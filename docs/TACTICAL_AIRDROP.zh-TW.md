# 空投支援：空中投標與投點

2026-11-16，接續9b13331的[預告攻防](TACTICAL_ENEMY_RESPONSE.zh-TW.md)。第二支援新增第三種行為「空投」，讓ZIP回郵標與LOOP甩線器在空中施放，沿用原Q／I戰術槽，不增加按鍵。

## 立即試玩

STORY據點→SKILLS→在回郵標或甩線器的第二支援選「空投／落地承諾」。支援可免費更換、存入原三套完整預設，其他技能的空投選項會停用並說明原因。

- **ZIP：Space起跳→Q投標→落地接近。** 投標按真位置向下斜飛，命中才標記敵人；空中投標傷害降低20%，基準8傷害變6，能量仍為原15（省能依原規則）。低空施放會較早碰地、射程較短，沒有自動瞄準或保證命中。
- **LOOP：Space起跳→Q投點→落地用原L／I網路招式。** 連接器沿斜線降至地面，或到原有界壽命時在末端位置設點。仍屬同一兩點網路，第三點替換最舊點，沒有空中免費多存點；能量、冷卻及節點壽命沿原變體／主支援／裝備。
- **留在地面按Q仍是原招。** 不扣空中預算、不加落地恢復，也不套空中投標減傷。第二支援占用同一格，因此不能同時裝回收／延時。

斜線以出手時角色高度決定，不追敵、不修改原傷害／格擋／Boss出口。畫面有可見的斜向軌跡，接點實際建立後才出現地面點；沒有用顯示層替模擬先放點或先標記。

## 空中資源與落地承諾

空投起手即消耗本次跳躍的`fast_used`預算，與原快速下墜、ZIP高架急件共用；不能靠二段跳再取得第二份。已用掉這份預算時拒絕空投且不扣能量。原二段跳／追擊／空反及滯空總預算都不重置，起手仍使用原有限攻擊滯空。

完成空投後，待原落地／招式恢復結束，再加8個模擬tick的落地恢復。期間不能以跳躍或另一招取消這份承諾；已緩衝的下一次跳躍／攻擊會等恢復結束才執行，避免被額外恢復吃掉輸入。若空投遭受擊或格擋硬直中斷，沿原硬直恢復並取消尚未兌現的追加恢復；不退已付費，也不返還本次空中資源。

HUD在合法空中待機時顯示「空投／真費用」，資源已用則提示落地；動作忙碌、能量與冷卻仍沿[共用就緒檢查](TACTICAL_USABILITY.zh-TW.md)。hitstop與暫停不推進承諾。離開故事／標準FIGHT與Demo不套用故事空投恢復。

## 存檔

CityProfile升至schema7，第二支援ID3代表空投。schema1–6保留原進度、貨幣、變體、回收／延時與完整預設，正常保存時保留版本備份，載入不改寫原檔。

schema6已要求存在的第二支援資料，遷移時仍屬必填；缺欄不能被當成更舊版本而默默補無。舊預設與新空投預設重讀後保持整數ID及裝備引用保護。
