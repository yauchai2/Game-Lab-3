# 技能操作、蓄力與構築體驗：詳細製作規劃

2026-11-16（Asia/Taipei）。基線 `9336bed`，接續 [技能與配裝主方案](SKILL_BUILD_DEPTH_PLAN.zh-TW.md)。本輪是設計與程式對照，**沒有新增runtime、改鍵或完成真人試玩**。以下按鍵、數字及門檻均為起測提案；本文件的輸入規格覆蓋主方案先前「新兩槽鍵位待定」，24招及章節設計繼續沿用。

## 1. 設計判斷與取捨

| 使用者提議 | 判斷 | 採用方式 |
| --- | --- | --- |
| 按住蓄力 | 採用，但限適合的技能 | RIVET作主樣板；其他角的持鍵改落點或時機，不統一變成蓄越久傷害越高 |
| J／K／L＋上下左右 | 部分採用 | 保留已存在的方向操作，逐步試少量K派生；不把三鍵乘四方向全部填滿 |
| H容易誤觸 | 優先解決 | H預設解除，戰鬥與據點都從Esc選單開指南；可自行重綁 |
| 利用Q | 採用作戰術槽A候選預設 | 單按立即施放，與第二槽I比較測試；不改成強制按住Q切整組技能 |
| 最後要好玩 | 作為內容裁減準則 | 每招必須改變選擇、能被理解及反制；若只有更多按鍵或更高傷害，退回重做 |

目標體驗：新手靠J／K、防守、L便能打出有效交鋒；學會新技後，可以主動逼敵人反應，再判斷接近、挑空、收尾或抽身。熟練收益來自確認、站位與資源分配。新招不是要求玩家在同一瞬間按更多鍵。

## 2. 原始碼現況與真正衝突

本輪查閱 `fight_session.gd` 的 `_player_command`／`_input`／鍵盤分派、`fight_controls.gd` 的solo／雙人／手柄映射、`fight_hud.gd` 的 `handle_shortcut`、`city/city_hub.gd` 的指南入口、`last_service/rules.gd` 的資源處理，並對照LAST_SERVICE_RUNTIME與故事引導規格。

- **J已是按住連段**：Rush每步讀取持鍵。若再用長按J判斷蓄力，就會延遲第一拳，或和自動續招競爭。
- **K已有模式差異**：正式Rush的地面heavy命令會設為挑空；空中會設為向下。不能把「普通K＝原地重拳、上K＝挑空」當成現在已有的行為。第一切片保留K習慣；重整K須獨立比較。
- **上＋L已是大招**：單人鍵盤由按下L時取W／上；不能把這個位置再分給一個可裝備技能。
- **RIVET已有真持鍵蓄力**：special到指定起手區讀 `skill_held`，12／30蓄力tick分階（既有perk可改第二階24），最長36tick；不能說蓄力要完全從零建立。動畫frame回到7延後釋放的現有方式，擴充前要測跳幀與取消。
- **LOOP下＋L已有node_pulse**：水平＋L亦影響遠點。全角把下L改第二槽會搶走已用功能；本輪不採用這種共通改法。
- **H是全域說明捷徑**：HUD收到H會開help；新據點另有H指南。只改戰鬥一處仍會留下據點誤觸。
- **Q沒有正式戰鬥動作，但並非完全無用途**：標題秘密碼最後一鍵是Q。新戰鬥用途必須限live play，保留標題序列。
- **I在單人可作候選，但雙人右側玩家已用作dash**。同鍵盤雙人必須各自配置，不能把solo鍵表全域套入。
- **F1目前開設定**：不把說明搬到F1造成另一個衝突。預設Esc→指南即可。

## 3. 單人鍵盤：推薦起測配置

以下是第一版要製作及比較的配置，不是本輪已改動的控制。

| 按鍵 | 建議用途 | 原則 |
| --- | --- | --- |
| A／D或左右 | 水平移動 | 沿現有平面，不新增3D滑鼠瞄準要求 |
| W／S或上下 | 技能方向修飾 | Space仍管跳躍，不因上＋招式順便跳起 |
| J／按住J | 輕攻與現有連段 | 首擊立即回應；方向先只影響移動／朝向，不增加四套隱藏招 |
| K | 現有地面挑空／空中終結 | 第一切片不撤回；上＋K作明示同義輸入，不能算新增招 |
| L／上＋L | 原招牌技／原大招 | 保留影片專用動作及成本；是否可蓄力按技能明示 |
| Q | 可裝戰術槽A | 預設放接敵／干擾工具，非限定此類；可與B互換 |
| I | 可裝戰術槽B | 預設放轉接／控場工具；與Q分置兩手，是否順手須試玩 |
| Shift／E／G／Space | 防守／閃避追擊／投技／跳躍 | 保留共通語義與原合法狀態 |
| Esc | 暫停、指南、操作、設定 | 全部可由選單取得 |
| H | 預設不綁定 | 不開頁、不吞J連段、不另作高風險戰鬥動作 |

**為甚麼選Q＋I起測：**Q方便左手，但與A同指存在移動代價；I在K上方，可由右手承接另一槽，不強迫左手同時負擔移動、防守、閃避與兩技。I仍可能被誤按，所以要比較Q＋U及自訂配置；不能只憑鍵盤圖認定舒適。若I的誤施放高，改預設而非要求玩家適應。

不採Q作常駐修飾鍵：Q＋J／K／L雖可減少右手伸展，卻增加三鍵組合、ghosting與移動同指衝突。亦不採Q開戰鬥輪盤作主要入口，避免每次出招都要停下選。

### 方向派生要有共同語義

左右寫成「前／後」，按出招採樣時角色面向轉換；不永久把D當前、A當後。上下是戰鬥平面的高／低語義，不是深度移動。

| 組合 | 規劃階段 | 行為與邊界 |
| --- | --- | --- |
| 上＋K | 第一版整理提示 | 沿現有挑空；不延遲單K，也不多扣一次費用 |
| 下＋K | 首八招穩定後比較 | 地面低位掃擊候選：低傷、短距、可擋，換較好的橫向控場；不是自動破盾／必倒。空中仍走原終結 |
| 前＋K | 後續比較，非首版必做 | 有承諾的踏入重擊候選；位移有上限，不代替E無敵，不與RIVET新肩撞重複 |
| 後＋K | 暫不加入 | 閃避與新反打技已有用途，先避免退走時誤出招 |
| 上＋L | 保留 | 原大招，按下時判定，不因後續鬆開W降級 |
| 下／水平＋L | 保留既有角色用途 | LOOP原脈衝及遠點保持；不當共通裝備槽入口 |
| 方向＋J | 首版不擴充 | 移動中連段要可靠。待證明有缺口才加，不為對稱湊招 |

第一版裝備技能與方向派生分清：Q／I從六個新增主動中選二；K派生若錄用是開局基本動作，**不佔兩槽、不重複列入24招**。招式主變體亦不另佔一鍵。

## 4. 蓄力：時間應換來選擇

四種持鍵體驗可以不同：

| 角色 | 第一候選 | 點按／短按 | 持鍵價值 | 必須保留的代價 |
| --- | --- | --- | --- | --- |
| RIVET | 現有L落鉚；新Q衝鉚彈 | 快出手、較小壓迫 | 預壓後更擅長逼盾／移位，傷害只適量上升 | 身體承諾、被側襲／投技打斷、長恢復 |
| ZIP | 新Q回郵標 | 依前方合法目標快投 | 短暫預覽近／遠落點，放開投出 | 不暫停敵人、不無敵瞄準，長按不憑空增加路線 |
| HUSH | 新Q斷拍線 | 快速窄線截擊 | 有限準備換更精準的指定穿透／距離用途 | 蓄時失去快速截擊時機；不擴大招架窗口、不自動取樣 |
| LOOP | 新Q甩線器 | 投預設落點 | 在有限距離內選設點位置 | 仍共用兩點名額，設點可被拆；不按久自生第三點 |

第一切片只製作RIVET新Q蓄力；其他三種先做點按完整招式，再決定持鍵是否真的改善操作。HUSH返聲取樣是有限接收／反射窗口，不做「一直按住便一直安全」的蓄力盾。大招先維持原按下承諾，不把所有L／上L改成放開才出。

### 起測時序與資源契約

- 新蓄力技：按下即進可讀準備姿態；短按放開發快速版。只讓標有蓄力的技能在release出招，J與普通即發技仍走press。
- RIVET新Q以 **0.25秒一階、0.60秒二階、0.90秒上限自動釋放** 作灰盒起點，採60Hz模擬tick即15／36／54。這不是現有L的12／30／36，要分開顯示與驗收；慢動作下牆鐘時間可不同。
- 第一版只做快速／滿階兩個作用結果，中間充能有提示但不再多一個傷害tier。若短按沒有競爭力，先調快速版用途，不能讓滿蓄成唯一正解。
- Q按下合法時暫扣基礎費用；二階跨檻合法時再扣差額一次。不足時停在可支付階，顯示狀態；不可負能量、不可預借未來命中回能。
- 候選：快速版20能量／4秒冷卻，滿階總30／6秒。費用在效果數字平衡前只是預算。取消／被打斷消耗已承諾能量並進對應冷卻；系統退出／回城則按既有模式狀態保存規則處理，不能把操作中斷當免費回能來源。
- 釋放時啟動對應完整冷卻；中斷亦進冷卻。使用唯一cast_id防同幀升階、釋放、取消重複扣款或重複命中。
- 滿蓄無精準一幀獎勵，沒有必須完美鬆鍵的甜點區。滿階後短時間內仍有明確上限，不能安全永久囤。
- 預設RIVET蓄時站定；ZIP／LOOP選點可低速移動（候選正常40%），均無免費無敵或通用霸體。既有L特定末段霸體保持獨立規則。
- 允許在未釋放前用合法防守／閃避取消，仍支付原能量／閃避費及冷卻；受擊硬直時不能藉取消取得防守。取消後不能再執行殘留release。
- 單鍵切換蓄力可作可及性選項：第一次按進入、第二次按釋放；相同模擬時間、上限、費用及風險，不按鍵連點提升效能。焦點丟失後取消，須新按才可重啟。

### 聲畫反饋

蓄力開始即有姿態／拳套反應，升階用兩種輪廓與不同節拍，角色旁的小刻度補充現有能量。F2與靜音時仍可看懂。釋放前可以打斷，真正命中才有撞擊重音；被擋、揮空、打中必須不同。不為普通蓄力技切長片或停背景音樂。

## 5. 輸入解譯：避免「我明明按了卻出錯招」

新增 `combat intent` 概念作共享輸入出口；不要只在單人 `_unhandled_key_input` 再加幾個KEY分支。

1. 鍵盤solo、split keyboard與手柄先各自映射為語義action，press／hold／release進同一採樣路徑；清除目前solo直讀Input與controls持鍵不一致的風險。
2. 方向在新按下時取樣並鎖定招式。前後按當時面向求出；敵人穿身不讓已選招式翻來翻去。特別標記可調落點的技能僅在釋放前更新合法預覽。
3. J按住時移動不反覆重新選一套新招。升階／release邊緣只發一次，鍵盤echo不算新施放。
4. 上下相反同按＝中立；左右相反同按＝中立。斜向若同時有上下修飾及水平，只選垂直分支；移動方向另留給原simulation。中立L仍可依LOOP既有水平規則選遠點。
5. 新press同tick優先：合法防守／閃避取消→上L大招→Q／I戰術技→其他明確attack→按住J續招。兩槽同tick只取一個，預設Q先；非法明確技能給失敗提示，不能暗中退回J或花另一招的費用。
6. 受擊、抓技、空中預算、收招及Boss狀態仍管合法性。只有逐招明示的hit-confirm取消點可轉接；不是按Q就取消所有招。
7. 新技能輸入緩衝先測6個模擬tick（約100ms正常速度），最多一份攻擊意圖，不建立長技能佇列。釋放、招式方向、來源裝置、slot與cast_id跟意圖保存。進受擊／過場時清理，避免恢復後突然出大招。
8. 消耗型動作以按下邊緣觸發，持鍵不反覆自動花能量。新蓄力鍵若在等待窗口內已鬆開，到合法窗口只做快速版，不憑失去的hold時間補出滿蓄。
9. 針對共用慢動作／hitstop定義一次採樣、多步模擬的命令消費；蓄力、冷卻都走同一simulation時鐘。凍結中不靠高render FPS累積額外蓄力。
10. 暫停不累積蓄力或冷卻；恢復前須確認蓄力鍵已鬆開，進中立狀態，不因視窗切換的release發射。死亡、讀檔、過場、離頁、重開、手柄拔除清intent與預留扣款狀態；不可跨角色接續。

### 手柄與雙人不能最後才補

- 手柄保留已有普通攻防及上＋B大招。候選A：左搖桿移動＋十字鍵左／右兩槽；可單鍵用技能，但左拇指要離開移動，所以需與候選B：右搖桿按下＋下B比較。兩者都有代價，**本輪不宣稱已有定案或人體工學驗證**。
- 使用十字鍵移動的玩家須有獨立預設／重綁，不能默默拿掉移動；若沒有一套能可靠操作兩槽的方案，不擴至24招。
- split keyboard的P2 I已是dash、P1 R已是skill，按玩家分別配置；全域help不能先攔截已綁戰鬥鍵。
- 重綁要檢查同玩家動作、跨玩家實體鍵及必要選單鍵衝突；同語義替代鍵可以並存。HUD／教學／技能頁取真實binding，不硬寫Q／I。
- 普通鍵盤測移動＋Shift＋技能＋方向的多鍵遮蔽；必要時提供較少同按的預設，而不是以軟體宣稱可修復硬體ghosting。

## 6. 首批八招如何形成可玩的循環

兩槽可自由互換；下表是教學預設。所有箭頭是情境中的合法選擇，不保證連續命中。若防住／揮空，顯示退路；被擊中才走真實取消窗口。

| 角色 | Q／I預設 | 一段實際決策循環 | 需要一起製作的敵人反應 |
| --- | --- | --- | --- |
| ZIP | 回郵標／折角踢 | Q標記後排→看是否有人攔路→I進場→J確認→K／E付費空連；盾擋則不盲追 | 隊長可走位、前排可攔路，退路封住便須停止追擊 |
| RIVET | 衝鉚彈／返工震線 | 快Q截住進場；敵人立盾時才蓄Q逼防→前進J確認→K；增援到地面路線再用I分隊 | 盾衛防彈但可投，突進兵懲罰貪蓄，射手迫使換站位 |
| HUSH | 斷拍線／返聲取樣 | Q抓射手恢復→走近；看到明示可反射彈才I接收→保留或返送→L反打 | 可反射與不可反射攻擊要不同輪廓，群敵能壓迫接收窗口 |
| LOOP | 甩線器／遙控混音 | Q設點→移動讓敵人靠近→短棍推回路線→I延遲脈衝；點被拆就回基本戰鬥 | 敵人會選擇拆點／跳離，但不每次立刻完美拆解 |

每角同時可用原L＋原大招＋兩新技；24招是可選池，不是24個需要同場背誦的快捷鍵。第一版先不讓一個技能同時「點按、長按、四方向、再按、空中」全有不同規則。每招最多一個額外操作概念。

## 7. 變體、支援與裝備如何影響操作

沿主方案的單主變體、最多兩支援、三槽裝備、暫限一件主要機制改造。首版只開**每招一個支援槽**，完成相容矩陣後才開第二；最終兩槽不是本輪一次交付。

| 層 | 玩家改變甚麼 | 第一個例子 | 禁止的重疊 |
| --- | --- | --- | --- |
| 主變體 | 招式的主要戰術用途 | 衝鉚彈選窄線破盾或短扇面散鉚 | 同時取得兩套覆蓋及收益 |
| 支援 | 帶代價的轉接規則 | 接力：真命中後下一個不同近戰有一次轉接收益 | 次生效果觸發自己、同招無限續回能 |
| 裝備 | 整段循環與資源取捨 | 壓力分流腕：用掉預壓換範圍作用 | 同一份預壓又享滿蓄單體、又出扇形 |
| 天賦 | 常用操作傾向 | 真防守後強化下一個指定技能 | 自動招架或完全消除揮空承諾 |

「預壓」支援若裝到原生可蓄力技能，第一版直接判不相容並解釋「此招已有蓄力」，避免蓄力套蓄力。後續若改成替換階段，必須明示新的曲線與代價，不做乘算堆疊。裝備不能改Q原本已選技能為另一隱藏招，主變體及支援也不偷偷改快捷鍵。

第一個比較樣板：RIVET快彈＋接力偏主動近身；破盾變體＋有限蓄力偏預判盾陣。兩者各在一類遭遇勝出，而非滿蓄配置在木樁、群敵和Boss都最好。所有射程、耗能、冷卻與取消說明依配置實際值顯示。
