# 街區成長與技能解鎖提案

2026-11-10。回應使用者「是否可以加入RPG、點技、加點、解鎖」：可以，適合加在單人街區挑戰及角色熟練度。這份是具體設計提案，尚未加入遊戲／存檔／選單，不把提案寫成已上線功能。

## 遊玩循環

選角色／流派 → 3場短街區挑戰（每場約45–90秒起步）→ 可選精英對手 → 頭目 → 結算熟練度、技能點、造型／終結演出 → 試新的技能組合。自由對戰、訓練及無限AI Demo仍直接可用；Demo不賺XP，四名現有角色和跳躍／格擋／反擊等基礎能力不重新鎖住。

建議第一版先做短關卡串連及本機熟練度，而非先造大開放世界、裝備掉落或網路帳號。先保留現有格鬥操作，讓成長改變打法及演出選擇。

## 加點：三條風格線，裝兩個戰鬥節點

| 路線 | 三個候選節點（由淺入深） | 設計限制 |
| --- | --- | --- |
| Flow／追擊 | 追擊成功回少量移動資源；解鎖斜向追擊變體；落地衝刺取消變體 | 取消仍需付費；不能無限空連；不能增加不可反制時間 |
| Resolve／反制 | 成功格擋回少量meter；選擇反擊角度變體；完美格擋後一次短位移 | 不把第一次玩家的基本格擋容錯鎖在天賦內；不自動格擋 |
| Pressure／爆發 | 蓄力分支選項；終結招式方向變體；專屬大招收尾演出 | 不加無條件必中／無敵；空揮仍付代價；演出不可改寫命中 |

每節點先用1技能點，不設付費重置；每角色同時裝備最多2個戰鬥節點，防止把所有優點永久疊滿。第一個有效分支應在首段挑戰後解鎖，完整一局後已有新選擇。具體節點要逐一以現有simulation驗證，目前未修改取消窗、傷害或meter規則。

如果之後要傳統屬性加點，可另開單人限定的體力／資源容量／移動三項，各3級、總增益先限10%附近，再作平衡測試；不改硬直、招架判定或動畫時間。第一版先不混入這套數值成長，避免無法分辨是操作進步還是數字碾壓。

## 經驗與獎勵

初始候選：完成一場30 XP；首次完成一種有效技巧20 XP（格擋、追擊、彈牆各只記一次）；敗北也保留部分完成獎勵。重複同一動作不持續刷XP，不設日常登入壓力。熟練度前5階可用每階100 XP作起始值，再依實玩調整。

裝飾解鎖優先：角色palette、入場pose、選角idle、名牌、街景燈色、KO收尾鏡頭。現有技能不變弱來強迫升級；不借用第三方參考人物／音樂當解鎖獎勵。

## 模式公平與存檔

- 標準對戰／未來多人：固定數值；可裝技能變體只在雙方使用同一規則集時開放，否則純造型。訓練可免費試所有節點。
- 單人街區：允許已解鎖build，對手有可讀的風格與關卡修正；保留原版純對戰可隨時返回。
- 本機保存於獨立 `user://neon_lab/progression.cfg`，schema version、角色ID／XP／解鎖ID、已裝節點分開。XP有界，未知節點忽略；原子存檔與備份；不覆寫options.cfg或原版設定。
- 成就以真實match result／真命中事件核發一次，重進結算不重複；Demo、fixture與重播不寫進度。沒有伺服器時不宣稱防作弊。

## 開發切片與驗收

1. 純資料熟練度＋版本化存檔＋一次性結算；檢查斷檔、重複結算、Demo無獎勵。
2. 原生UI的3×3技能板與免費重置／訓練試招；清楚顯示「已解鎖」「已裝備」「此模式不生效」。
3. 三場街區串連＋一位精英；先僅3個可裝節點，驗證能各形成不同打法。
4. 才擴展到9節點／角色差異／頭目／外觀獎勵。重跑公平對戰、反制、取消窗與空連反作弊界限。

實作前不需要另買素材或加入帳戶系統。可沿現在四角色、同一張地圖的環境變體及短演出完成第一段體驗。
