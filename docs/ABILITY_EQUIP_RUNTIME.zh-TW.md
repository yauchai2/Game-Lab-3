## 正式流程

DRAW → 三輪開獎 → 能力結果卡 → **EQUIP** → 4.10 秒裝備 → 下一局原倒數／戰鬥。正常模式仍需玩家按 DRAW 及 EQUIP；Demo 展示代幣 3 秒自動抽取、結果停 3.5 秒自動裝備。裝備已介紹角色，不再重播第三局的 2.8 秒人物開場。

影片以完整時長 4fps 掃描及代表畫面檢視，原檔／SHA／contact sheet 留在 `references/ability-equip/`。原片前半秒含分鏡畫面，後段是接握、橫轉、腰扣、腿部能量及鞋底重拍；遊戲重做為連續真 3D 動作，沒有播放原片或烘焙 2D 人物。節奏及鏡頭是近似重建，並非來源逐幀或逐像素復刻。

## 模型與跨場景

使用**當局 P1 所選原 GLB 的演出副本**，含 ZIP／RIVET／HUSH／LOOP／BLACK SUIT；不是固定紫衣人，也不修改選角或原檔。抽獎段依舊只有 NPC／機器；裝備段只拍手、腰、腿與鞋，五角色六個主要時點皆驗頭部在畫外。鞋鏡採斜上取景，避免原街景前景物遮住鞋。

所有演員以原 ability stage profile 的原點／朝向／地面高度定位；使用當局街景，不另加固定背景。手腕以骨架真比例求解，鬆手回可達的原待機位置；夾具鎖住後核心停在 socket。LOOP 演出副本暫不顯示手中 baton 以免與握核心相交，正式戰鬥原道具保持。

九核心共用動作，各保留自身色彩／圖示。`core_prop.gd` 共用實體膠囊、端蓋圖示、橙色夾具及狀態燈；過場後由 `fighter_visual.gd` 依當局 `draw_core` 建立真正可見腰掛，按 Hips 的骨骼變換跟隨移動／姿態，下一局結束或重設沒有該欄位時隱藏。沒有修改碰撞、傷害或額外授予速度。

## 時鐘、輸入與清理

`cinematic/ability_draw.gd` 仍是唯一鏡頭／lens／音效／狀態 owner，新增 equip 狀態；`equip_view.gd` 只按局部作者時間採樣。原 fighters／影子／生活 NPC 維持隱藏；演出副本不寫入 simulation。演完或 Space 跳過後才建立下一局並套用已鎖定能力一次；反覆 Enter 不穿透跳過裝備。取消／重開／退出不發獎，恢復鏡頭、原角色顯示、音樂 duck，停止 cue、關閉副本／lens。

暫停凍結時間與實際音軌；開場已啟用 F2 時採 1.15 秒短版與獨立同步 PCM，保持握取／鎖定／踩地但關閉強後製與大部分煙塵。中途 F2 即時降低特效，保留開始時選定的時長及聲畫對位。

原創 PCM cue 由 `python tools/build_ability_equip_audio.py` 重建，full 4.10s／short 1.15s，不變調、不用原片音軌。沿用 SFX bus、mute／effects volume、BGM duck；不停止長 BGM transport。原始 GLB、抽獎素材、音軌與永久 XP 保留，公開 Web 未更新。
