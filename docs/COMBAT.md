# Afterhours：街頭格鬥原型

> 最新規格見 [EXTENDED_POLISH.md](EXTENDED_POLISH.md)：現有無限練習、14 段 CC0 動作及授權音訊、三階壓力、G 投技／拆投、E 場邊受身、繁中 UI 與獨立音量。下文保留首輪原型數值與歷史範圍，不能把「未做練習／動畫／音樂」當成目前狀態。

## 方向與範圍

2026-11-07 使用者在本聊天明確指定：「類 Lethal League Blaze 但不是擊球，而是打鬥」。因此將 LLB 文件的圖形特效、頓幀與聲音分層轉譯為角色近身格鬥，沒有建立球體或把球速當成戰鬥核心。

以 `codex/flight-street-handoff` 的 `f9cd82d` 為場景來源，在獨立 `codex/street-combat` 分支製作。此輪交付可玩的單機 2.5D 玩家對 AI 原型；Afterhours 為暫用名稱。保留原街景遊走、來源角色 GLB、原始模型與歷史驗證。兩位角色暫共用使用者提供的模型並作不同染色，並非兩套完成角色。

## 執行與操作

Godot 4.6.3 開啟 `godot/project.godot`，按 F5（執行專案）啟動格鬥主選單。在遊戲內 F6 可切換格鬥與原遊走場景。

| 操作 | 按鍵 |
|---|---|
| 左右移動 | A / D 或方向左右 |
| 跳躍 | Space |
| 輕攻擊、確認命中後接三段 | J；命中後再按，可在頓幀緩衝 |
| 重攻擊 | K |
| 挑空 | W + K 或方向上 + K |
| 能量技 | L，消耗 50 能量 |
| 地面防禦 | 按住 Shift，面向對手 |
| 翻滾閃避 | E；按 A/D 控制方向，無方向時向前 |
| 暫停／繼續 | Esc；視窗失焦也暫停 |
| 下一回合／重賽 | 結算介面 Enter |
| 重開比賽 | 暫停／結算時 R |
| 音效開關 | M 或選單按鈕 |
| 減少反白和鏡頭震動 | F2 或選單按鈕 |
| 顯示判定範圍 | F3 |
| 返回街景／從街景進入格鬥 | 遊戲內 F6 |

主選單可選 AI 對戰或固定對手練習。練習仍使用完整回合規則，未做無限生命或錄製回放功能。

## 已實作規則

- 每回合 100 HP、75 秒，先取兩回合者贏；時間用盡比較生命，平手不加分並重打。
- 60 Hz 確定性模擬，展示用獨立時鐘；暫停不推進戰鬥。
- 起手／有效／收招分開；每次攻擊最多命中一次，判定考慮距離、朝向、雙方高度及衝刺無敵。
- 輕攻擊命中可在收招期取消接續：jab → cross → finisher；連段傷害每段遞減，最低 45%。
- 輸入緩衝 10 個模擬幀，在頓幀期間保留。防禦消耗防禦槽，破防造成 65 幀硬直；不設扣血式防禦磨血。
- 挑空、空中受擊、推退、地面碰撞、角色互推、場邊限制；衝刺前 7 幀無敵，42 幀冷卻。
- 命中雙方累積能量，能量技需 50；不足時以文字提示。
- AI 有固定反應節奏、接近、攻擊、防禦及偶發重招／能量技，不用逐幀完美反應。

### 招式初始數值（60 Hz）

| 招式 | 起手 | 有效 | 收招 | 基礎傷害 | 頓幀 |
|---|---:|---:|---:|---:|---:|
| Jab | 5 | 5 | 13 | 7 | 5 |
| Cross | 6 | 5 | 15 | 9 | 6 |
| Finisher | 9 | 6 | 23 | 13 | 9 |

## 美術與演出實作

- 復用港式街景遠側立面和招牌，近側量體只在格鬥組裝場景隱藏，避免遮住戰場；原街景不改。
- 原始角色 GLB 外掛三階 toon、隊伍染色、受擊反白及反向殼；殼使用現有法線，尚未做平滑法線資料通道，可能有裂縫。
- 程序骨架站姿、移動、跳躍、出拳、踢擊、挑空、防禦及受擊姿勢；15 Hz 姿勢取樣是臨時動作，並非手工完成動畫。
- 揮擊弧、星芒、環形衝擊、煙塵為自製幾何 2D 圖形和分階演出，尚未換成手繪 Flipbook。
- 動態鏡頭跟隨與縮放、命中震動、頓幀提示條；F2 關閉震動和受擊反白並縮減高亮演出。
- 原創合成揮擊／接觸／蓄力／出招音效，使用獨立播放池，可靜音；尚未人工試聽和混音。
- 鍵盤可操作原生按鈕、可見焦點、失焦暫停、重賽和回到街景。

## 程式分工

- `fight_simulation.gd`：純遊戲狀態、規則和事件，不依賴 3D 場景。
- `fight_session.gd`：組裝、輸入、鏡頭、場景轉換、事件派發。
- `fighter_visual.gd`：外掛材質、骨架臨時姿勢，來源資產無修改。
- `fight_hud.gd`：生命、能量、防禦、連擊、選單與 2D 演出。
- `fight_audio.gd`：自製測試音效及播放池。

## 詳細後續開發順序

1. **手感驗收**：真人試玩現有對戰，調整移速、攻擊距離、起手／收招、頓幀、AI 與防禦壓制；固定一組可重現的驗收對局。
2. **動作與美術**：製作可區分的輕拳、重踢、挑空及必殺動作，重做角色戰鬥剪影；手繪 4–6 張特效序列，改善平滑描邊法線、背景遠近對比和命中瞬間演出。
3. **格鬥深度**：完善空中追擊與落地硬直、防空、投技及投技對策，再決定是否加入格擋反擊；先列判定與優先級再加招式。
4. **練習工具**：無限生命、對手防禦／受擊設定、輸入歷史、連段挑戰、AI 難度、手柄及按鍵設定。
5. **內容擴展**：第二位獨立角色、招式差異、角色選擇、另一場景；復用現有港式資產，生成新素材前按用途與來源驗證。
6. **交付與效能**：真人測試、目標 GPU 測量、音訊混音、桌面匯出和可攜執行包。輸出平台尚待選定，不能從軟體渲染推斷 60 FPS 達標。
7. **多人**：先考慮本機雙人；連線／rollback 需要獨立架構和同步驗證，未列為本輪完成。

原 LLB 文件的四週安排保留作來源，不當作已執行的排期或此次完成承諾。

## 重現驗證

```sh
godot --headless --editor --path godot --import --quit
godot --headless --path godot --audio-driver Dummy --script res://tools/verify_combat.gd
# 需要可用顯示服務；本輪用 Xorg dummy + Mesa llvmpipe。
DISPLAY=:94 LIBGL_ALWAYS_SOFTWARE=1 godot --path godot --rendering-method gl_compatibility --resolution 1280x720 --audio-driver Dummy --script res://tools/capture_combat.gd
```

結果見 `docs/evidence/combat/`。Headless 只證明邏輯／載入；llvmpipe 圖只證明特定軟體繪圖路徑。尚未做真人手感、實際聲音或目標 GPU 驗收。

自動示範 `evidence/combat/scripted-demo.mp4` 為 7 秒、420 個固定時脈幀，含 4 次命中與 1 次格擋；輸入由 `combat_demo.gd` 提供，輸出為靜音，不是人工試玩或即時硬體效能影片。另保留 960×540 選單與戰場截圖。
