# 蓄力重砲與分招式演出

2026-11-09。延續上一輪停慢快節奏，新增一個需要累積能量的重砲選擇，讓普通爆發、空中追打與大招有更清楚的層次。

## 操作

- **L**：原本的 50 能量爆發，保持不變。
- **W＋L／↑＋L**：**75 能量蓄力重砲**，四位角色皆可使用。按下便承諾起手，不需要持續按住；不是按住多久決定威力的自由蓄力系統。
- 按住 J 仍可地空連段；已確認的連段可接重砲，手動指令不被持續 J 吞掉。

主選單 Enter 對戰、T 自由練習或 F12 無限雙 AI；F2 返回普通速度／減少演出。對戰開局只有 60 能量，先用連段／防禦累積，再試重砲。自由練習起始 100，適合直接測試。HUD 及說明頁已加入 W＋L，能量不足會顯示正確的 75 提示。

## 真正的風險與回報

重砲使用獨立 `overdrive` 招式：起手 30／有效 8／原始恢復 42 simulation tick，基礎傷害 38、射程 3.8m，26 tick 命中停頓。正式 Rush 恢復倍率及既有連段減傷／反擊加成仍適用。只在正式／自由練習／Demo 的 arcade 規則開放，專用舊教室保持原控制。

能量在發招時支付，空揮不退、不自動命中；每次攻擊只命中一次。起手仍會受傷，抵抗普通拳腳中斷，**投技能真正打斷**。不是無敵或遠距離無條件扣血。受擊者依原規則獲得受傷能量，並未取消既有回報。

## 動作、紅幕及鏡頭

- 起手：身體後壓、雙手後拉，逐漸收束的八角能量環，獨立紫紅 **MAX OUT** 紅幕，最長 1.45 秒。
- 釋放：雙掌向前、判定幀雙手放大；真命中停頓結束後才出現硬邊光束與環形衝擊。光束由角色手部附近射向實際接觸點，配合護目鏡角色 4 的 1.4 倍模型縮放。
- 新節奏：0.20 秒全停、0.34 秒 0.22x 慢鏡、0.38 秒 1.95x 釋放；命中紅幕最長 1.1 秒，BREAK／KO 可接管。音樂保持原速。
- 重砲用較低視點及慢鏡 38° FOV；暴扣改成向下壓的視點，格擋／反踩反向繞行，避免每招都同一方向甩鏡。
- 地面挑空新增收身／上勾姿勢，與暴扣及雙掌重砲分開。這些是疊加在既有 CC0 動作上的原創程序姿態，不是新下載動畫檔。

無限 AI 在自己完成包含空中攻擊的至少五連後記住重砲機會，等待站位與 75 能量，再透過合法指令施放；每方重砲選擇至少間隔 600 simulation tick，普通爆發的原有節奏也保留。沒有預設章節、瞬移、強塞能量或假的命中。
