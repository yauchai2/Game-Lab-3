## 招式時序

為讓兩踢之間真的有收腿／落腳／轉髖，命中後續踢延遲從4改為16 simulation ticks，active總段從10改26，起手14與基礎恢復28保持。正式arcade仍沿既有恢復倍率及停慢快時鐘；不把4秒參考片直接變成強制4秒控制鎖。
