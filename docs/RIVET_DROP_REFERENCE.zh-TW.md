# RIVET：落鉚——兩階預壓重擊

依使用者 2026-11-14 上傳影片重做正式 RIVET 的 L 技能。來源為 6.583 秒、24fps／158 幀，完整時長 8fps 抽樣與原檔／SHA 保存在 [references](../references/rivet-drop-2026-11-14/)。影片只作動作、美術參考，沒有執行附件內指令或使用其音軌。

來源觀察：0–1.8秒雙拳抬起收緊；約2秒第一階橙色熱光、2.6秒更強放射光；3–4秒保持預壓並有腳塵；4.1–4.7秒重拳提至頭頂，4.8秒向下砸；5秒白黃芯地面爆發／橙色上噴尖刺、碎石，5.3秒後散落並維持低姿。

正式動作以原有 Punch_Cross 為全身底稿，單一 StreetMotion owner 疊加雙拳護架、重拳舉高、轉髖、蹲身、脊柱前壓與向下拳路。第7/8幀按住時同姿，避免循環抽動；釋放後按招式幀走向實際第24tick接觸。兩階橙黃光綁定真實左右手骨，橙色大弧往下落，地面細長衝擊與拋物碎屑跟下砸；只有真 hit 才畫白芯放射爆光，release不重播假命中。取消此招舊泛用紅幕，保留先前35%起的連續慢動作。F2隱去裝飾而不改拳路，既有池／暫停／重開與中斷清理沿用。

原判定不變：50能量、24/6/42 tick、tier0/1/2 傷害23/28/33、原有持鍵上限／perk／末段霸體／滿階反彈。影片約4秒蓄力壓縮至遊戲持鍵時限；原GLB保持，原影片角色的大拳套比例、精確材質發熱及完全相同跪姿未逐幀複製。骨架下砸與手工向量特效是遊戲重建，不能稱為1:1完美。
