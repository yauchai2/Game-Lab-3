# 動能換手與漫畫爆發演出

2026-11-09。延續 [爽感優化路線](GAME_FEEL_ROADMAP.zh-TW.md)，本輪已實作 **P1a 練習原型及第一版 P2 視聽演出**。正式對戰保持原有壓力三選，不把尚未經真人比較的新模式直接替換進去。

## 現在怎樣試

GitHub Desktop 拉取 `codex/street-combat` 後，以 Godot 4.6.3 開啟 `godot/project.godot`、F5 執行：

- **Enter／街頭對戰**：直接比較更強的重擊、能量技及 KO 演出；J 輕拳、K 重踢、W+K 挑空、L 能量技。
- **F10／動能換手・實驗練習**：等對手出拳，在接觸前輕按 Shift。取得主動後，在壓縮停頓期間按 J 鎖定反擊；對手再格擋就會換手升級。輪到防守時放開 Shift，等出拳動作再重新按下。
- **F10 再試、F5 回自由練習**。F8 仍是原有三選教室。兩套機制不會同時開。
- **F2 減少演出**：關分色、骨架殘影、方向衝擊線、鏡頭反衝與動態縮放，保留接觸環／等級／操作提示。
- **Esc 暫停；Enter 可跳過 KO 演出**，直接下一回合或重新開始整場。

[換手短動畫 GIF](evidence/kinetic-overdrive/previews/rally.gif)／[MP4](evidence/kinetic-overdrive/previews/rally.mp4)；[能量技爆發](evidence/kinetic-overdrive/captures/special_release.png)、[壓縮至第四級](evidence/kinetic-overdrive/captures/rally_tier_4_compress.png)、[KO](evidence/kinetic-overdrive/captures/knockout_impact.png)。影片來自原生 Godot 固定 60Hz 指令重播、隔 tick 擷取；不是即時 FPS 或真人操作錄影，無錄音。

## 明確保留的後續範圍

這一版只有**快反**，尚未接 P1b 的 K 持放蓄力、連鎖付費投技／拆投或正式 AI 的多分支選擇。實驗 E 仍沿用普通免費閃避；不是計劃中 20 能量的連鎖脫離。練習會補滿能量，不能拿它作正式資源平衡結論。

選角、第二名獨立角色、VS、延遲蓄力、整場級別的長 KO 演出仍未實作。本輪不用 Tripo，也沒有新增下載音樂；沿用已有授權音樂、音效及動作，新增短音由程式合成。挑戰 AI 被固定輕拳節奏壓制的既有問題仍待真人調校。

## 規則及清理契約

`fight_simulation` 是唯一規則時鐘；新連鎖活躍時，不執行普通攻擊／一般 hitstop 或三選停頓。初次格擋給既有能量／壓力一次，後續不反覆刷資源；命中只結算一次，攻擊緩衝在結束時清除。

展示時鐘繼續播放接觸特效，真正暫停則兩者都停。每次重新開始、F5、下一回合、回標題都清空待釋放效果、核心、分色及鏡頭衝擊；離開場景時節點一起釋放。KO 不再依賴已凍結的模擬反白倒數，沿用上一輪展示修正。沒有全屏高頻閃白。
