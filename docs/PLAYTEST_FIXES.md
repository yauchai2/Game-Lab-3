# 試玩回饋修正：朝向、動畫、斑馬線及鏡頭

## 使用者五點回饋（2026-11-07）

1. 角色背對背，需面向對手。
2. 動作不足，希望使用網上平台（例如 Mixamo）的較完整動畫。
3. 附圖只是背景指引，不要求極低仰角；角色可在街前斑馬線戰鬥。
4. 左右移動時鏡頭可以輕微改變角度。
5. 場景文字先移除，等待使用者提供招牌等貼圖。

這些回饋取代 D038／D039 的固定低仰角和雙 world 合成選擇，舊文件及證據保留作歷史。

## 已修正

### 面向對手

原先把模型 +Z 前方用 −90° 轉到遊戲 +X，實際變成 −X。現在 face=+1 時使用 +90°，face=−1 使用 −90°。角色換邊後仍跟隨模擬的 facing；攻擊時保留鎖定朝向。驗證同時檢查實際模型 basis、換邊後的畫面，以及刺拳手部前移，不只檢查遊戲 face 整數。

### 外部動畫與骨架轉接

選用 [Quaternius Universal Animation Library Standard](https://quaternius.com/packs/universalanimationlibrary.html)，官方標示 **CC0 1.0**。由 [公開 glTF 鏡像](https://github.com/J-Ponzo/gltf-universal-animation-library) 的固定提交 `e24c23cf2a1323488a3faa226ea7ea21f644b73e` 取得，保留來源 URL、原始／衍生 SHA-256 及完整 CC0 授權。

只匯入 14 段動作資料，沒有匯入示範人物網格：拳擊進入站姿、刺拳、直拳、胸部／頭部受擊、走路、慢跑、快跑、起跳、空中、落地、翻滾、死亡、施法發力。來源及原始雜湊見 `references/animation-sources/quaternius.json`；衍生資料與授權位於 `godot/assets/animations/`。

`combat_motions.gd` 把 Quaternius DEF 骨架對應到現有 mixamorig 骨架，按休止姿態的全域旋轉差轉接，並校正原模型垂手姿態與來源綁定姿態的差異。包含身體和手指，使用者的角色 GLB 不改。四元數以 slerp 插值，切換有短混合，按取樣手部最大前伸位置校正拳擊接觸相位，接觸姿勢對齊招式起手／有效／收招，頓幀停止動畫取樣。水平 root motion 由遊戲模擬控制，只保留小幅髖部上下運動。攻擊另有 0.45–0.60 m 的視覺踏步，依雙方距離限幅，減少拳腳在身前落空；不改物理座標或命中距離。

- 站立使用拳擊架勢，前後移動切換／反向播放步態。
- 輕連擊使用刺拳與直拳；免費標準庫沒有重踢和無武器上勾拳，因此重踢／挑空是加在來源動作上的自製肢體方向調整，未宣稱來自下載庫。
- E 的衝刺以翻滾閃避呈現，規則仍是原本的短無敵／冷卻。
- 跳躍分起跳、空中和落地；受擊分胸／頭，KO 使用死亡片段。
- 能量技使用施法發力片段。動畫已接入，但接觸姿勢、腳步及極端體型的轉接仍需真人手感調整。

可重現匯入：`python3 tools/extract_combat_motions.py /path/to/pinned/gltf-and-bin`。工具只抽取本次選用的旋轉與髖部位移，6 位小數；不需要 Blender、帳戶登入或付費服務。

### 同一條斑馬線與同一個透視世界

移除獨立 SubViewport／Canvas 背景合成。街道、兩位角色、接地陰影、客機和主相機現在共用一個 3D world。角色位於世界 Z=3，與原街景斑馬線中心一致；道路用現有場景，刪除臨時加上的平面、起點光圈及舞台邊界塊。

街道包裝 X 縮放 2.4，讓現有 ±8.2 的格鬥範圍落在道路內。來源場景、模型和原街景遊走的空間尺度未改；這是格鬥包裝的場地配置。

主相機使用透視 FOV 48°，初始位置 `(0,1.7,16.5)`，看向 `(0,2.45,3)`。不再強迫整幅畫面仰望天空；左右店面、斑馬線、角色腳底與後方車輛共享透視和視差。

### 輕微追鏡與轉向

以雙方中點平滑追蹤；依分離距離控制距離 13.5–17.2 m。中點左右移動產生最多約 ±5.7° 的環繞偏移，讓街牆與招牌產生合理視差；維持世界 X 軸左右操作，不隨鏡頭改按鍵方向。跳躍略微提高注視點。

### 場景招牌留白

`street_dressing.gd` 預設 `show_sign_text=false`，不生成招牌字或帶字塗鴉；格鬥與遊走包裝隱藏既有 Label3D 和 SignGlyphProxy 幾何字。招牌框和空白面板保留，等待使用者素材。生命、操作提示和選單等遊戲 UI 保留可讀資訊。
