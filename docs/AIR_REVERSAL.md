## 如何試

1. 拉取 `codex/street-combat`，Godot 開啟專案後執行。
2. **F11** 進自由空戰；再按 **F8**（或右上按鈕）進空中反制教室。
3. 先不限時閱讀，按 **K** 開始。對手終結招接觸前，見「現在！」按一次 **Shift**。
4. 成功後 **J 反踢**／**E 安全抽身**，也可點按按鈕。首次選擇鎖定；沒有選擇則抽身。
5. **K 再試**、F11 回自由空戰、F5 回普通練習；F2 減少演出。

自由空戰內同樣可對空中終結踢或暴扣反制；陪練模式的中／高 AI 也會依公開起手嘗試，並非只在教室作弊觸發。教室固定站立腳本，刻意讓雙方在空中等待讀招；這個預備姿態不是正式物理規則。

## 規則與取捨

| 項目 | 60Hz 規則 |
| --- | --- |
| 啟動條件 | 雙方離地、對手終結踢／暴扣起手、前方及距離內；防守方待機或受擊硬直中 |
| 資源 | 嘗試花 25 能量；每次離地只可嘗試一次，落地恢復；太早按也消耗，不靠連按洗窗口 |
| 有效窗口 | 新按 Shift 後 6 tick；按住不反覆觸發，能量不足不消耗額度 |
| 換手定格 | 18 tick；取消原攻擊、保留位置及朝向，首次 J／E 選擇鎖定 |
| 反踢 | 10 tick 起手、4 tick 判定、命中一次 18 傷害；對手在起手可 E 閃避或移動離開 |
| 抽身 | 無傷後撤、短暫無敵；不選擇也安全退出 |
| 終止 | 最多 90 tick 防呆；反踢不能再次觸發此逆轉，避免空中無限互鎖 |

換的是攻守主動權，**沒有瞬移換座標**。保留身體位置讓命中與閃避可預判；抬腿踩踏／受擊後仰為原創程序姿態。現有連段、追擊及停留額度不會因此補滿。自動陪練在選擇前按固定序列承諾反踢／抽身，不讀玩家待送選擇。

## 演出與介面

接住時保留硬邊核心與短定格；反踢有起手、斜弧、命中核心、釋放環和合成音，抽身使用現有衝刺音。角色使用抬膝踩踏／後仰姿態，F2 停強變形及速度線。雙語提示與原生按鈕共用同一輸入提交；暫停、教室重試、切模式及返回清掉定格核心、聲道與待送選擇。

原 GLB、車輛、天空、音樂音效來源不變；字體只重建繁中子集。wev 尚未授權，仍只規劃；目前不需要 Tripo 新模型。
