# 參考式五人群像：構圖及角度修正

2026-11-10，使用者回報上一版Layout／角度古怪，要求多人並更貼近TR3B參考。沿用已歸檔原片，將人物數目、前後層次、色彩與街角方向作主要構圖依據。

- **前景**：HUSH桃紅、ZIP青色，放大輪廓，手落在腰側，維持放鬆姿態。
- **中景**：RIVET黃色，與前景分開；**後景**：LOOP紅色、另一位ZIP螢光綠剪影，手勢與擺動錯拍。
- **完整畫幅**：使用640×360、16:9獨立3D場景，原比例畫到整個畫面，再疊上固定左選單。拓寬道路，讓建築、斑馬線和人物共用透視。
- **固定軸線**：鏡頭維持同一街角方向，較低眼位、6°輕斜鏡；只有微小平移／拍點推近，取消前版四段換角度和大幅遠近切換。
- **同構圖fallback**：減少特效和首次載入使用這個五人場景的原生靜態渲染 `cover-ensemble.png`，讓畫面連續。舊兩人海報仍保留。

第五位是背景演員，沒有增加第五個可選角色或多人戰鬥模式。所有剪影維持無五官／無項鍊；原GLB不改。12Hz動作採樣、8秒循環、離頁停渲停鐘、連續音樂規則保留。這是以現有角色重建參考的群像關係，不是原片逐幀複製。
