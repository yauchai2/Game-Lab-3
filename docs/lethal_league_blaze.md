# 《Lethal League Blaze》戰鬥打擊感與視覺特效開發計劃

要重現《Lethal League Blaze》極具爆發力的戰鬥打擊感（參考對戰影片：https://www.youtube.com/watch?v=lEy9hTvaf0s ），核心在於將 **3D 角色與場景**、**純手繪日式 2D 序列幀特效（Flipbook VFX）** 以及 **隨球速動態成長的頓幀系統（Hitstop / Hitlag）** 深度綁定。

---

## 1. 視覺與渲染底層架構（3D 混合 2D 賽璐珞風格）

《Lethal League Blaze》採用 3D 角色模型搭配 2D 平面戰鬥視角，透過高對比色塊讓高速移動的球體保持極佳的視覺易讀性：

* **角色三階色塊與粗黑外描邊：** 角色使用無漸層的 Flat Toon Shader（亮面、暗面、高光邊緣），搭配背面法線外擴（Inverted Hull）生成的粗黑外框線，確保在複雜背景前輪廓分明 `[00:00:04]`。
* **受擊與發力瞬間的純色反白／剪影切換：** 當角色被高速球擊中或觸發特殊動作時，將角色材質球瞬間切換為 Unlit 純白或高對比黑白剪影（如影片中角色被擊飛時的純白硬直狀態 `[00:00:15]`），強化視覺衝擊。
* **2D 特效與 3D 空間的圖層分離：** 幾乎所有打擊、煙塵與揮擊特效皆不使用傳統 3D 細碎粒子，而是採用固定朝向攝影機（Billboard）的 2D 手繪序列幀貼圖，並強制設定在角色圖層正前方（關閉 Depth Write 或偏移 $Z$ 軸）以避免穿模 `[00:00:07]`。

## 2. 核心 2D 打擊效果拆解與美術規範

遊戲的特效由手繪 2D 動畫構成，走日式作畫（Sakuga）的「低張數、高張力」路線，可拆分為五大模組：

1. **揮棒刀光／殘影（Swing Smears）：**
   * 揮擊瞬間生成大型的新月形雙色色塊（如外圈青藍、內圈純白 `[00:00:07]` 或亮黃色塊 `[00:01:15]`）。
   * 生命週期極短（僅 $3$ 至 $5$ 幀），前 $1$ 幀瞬間放大至最大面積，隨後 $2$ 至 $4$ 幀快速從尾部收縮消失，不留半透明殘影。
2. **擊球瞬間的同心圓與十字星芒（Hit Sparks & Shockwaves）：**
   * **多層幾何爆裂：** 擊中球體時，在接觸點生成「中心純白圓核 + 外圍雙色圓環（藍／白或紅／白）+ $4$ 至 $8$ 道不規則尖刺放射線」`[00:00:09]`。
   * **鎖定頓幀縮放：** 在頓幀（Hitstop）期間，該 2D 特效並非靜止，而是以高頻率微幅抖動或分階擴張，並在球飛出瞬間產生一道反方向的圓環氣浪 `[00:00:23]`。
3. **極限球速的黑洞閃光（Impact Frames）：**
   * 當球速突破高段位門檻時，擊球瞬間會覆蓋一個佔據畫面 $\frac{1}{4}$ 的巨型黑白撞擊閃光（中心漆黑球體搭配橫跨畫面的純白銳利十字星芒）`[00:01:58]`。
   * 透過瞬間遮蔽局部背景並拉高黑白對比，模擬熱血動畫中的「作畫黑白閃（Impact Frame）」`[00:03:49]`。
4. **球體拖尾與牆面反彈（Ball Trail & Wall Bounce）：**
   * **Ribbon Trail 拖尾：** 球體後方掛載一條隨速度拉長的扁平錐形色帶，顏色依最後擊球者的隊伍色（紅／藍／黃／紫）即時切換 `[00:01:39]`。
   * **牆面撞擊噴濺：** 球撞牆瞬間在接觸點法線方向生成貼牆的黃色或白色尖刺爆裂圖案，搭配向外噴射的塊狀煙塵 `[00:00:21]`。
5. **地面煙塵與落點反饋（Ground Dust）：**
   * 起跳、急停、落地與擊球後座力皆會在腳底生成貼地擴散的白色水花狀煙塵環，煙塵邊緣銳利無柔邊，結束時直接裂解成小色塊消失 `[00:00:33]`。

## 3. 動態頓幀系統（Dynamic Hitstop / Hitlag）與全屏異空間演出

《Lethal League Blaze》最核心的打擊爽快感來自「越快越慢」的節奏反差——球速越高，擊球時的停頓時間越長：

* **頓幀時長公式與緩衝操作：**
  * 頓幀幀數與球速成正比（低速約 $6$ 至 $10$ 幀 `[00:00:05]`；中高速可達 $30$ 至 $60$ 幀以上 `[00:00:42]`）。
  * 頓幀期間，球體與揮擊角色的物理位移完全凍結，但開放玩家輸入方向鍵改變擊球角度（Angling）或消耗能量發動 Special / Parry。
* **頓幀期間的蓄力表現：**
  * 角色模型與球體在原座標進行高頻隨機偏移（Jitter），視覺上呈現力量壓抑不住的震動感 `[00:00:56]`。
  * 畫面下方的音響（Boombox）UI 設有專屬的倒數進度條與速度錶（Speed Meter），將無形的頓幀時間轉化為可視化的蓄力讀條，讓雙方精準預判球飛出的那 $1$ 幀 `[00:00:13]`。
* **高速階段的全屏背景切換（Eclipse / Red Shift Mode）：**
  * 當球速突破特定閾值（例如影片中速度達 $150$ 至 $200$ 以上時 `[00:02:11]`），整個 3D 背景環境會瞬間切換為猩紅色高對比剪影，同時球體變成純黑核心配暗紅外框 `[00:04:47]`。
  * 實作上可使用全域 Post-Processing 或獨立的背景材質參數（Global Shader Parameter），在球速達標時將背景貼圖轉為單色調（紅黑），把所有視覺焦點強制鎖定在球體軌跡上 `[00:06:05]`。

## 4. 鏡頭運動與音效疊加（Camera & Audio Juice）

* **方向性鏡頭震動（Directional Screen Shake）：**
  * 摒棄純隨機亂晃，改用「沿著擊球向量方向」的瞬間推拉（Punch）搭配衰減彈簧震動（Damped Spring）。
  * 在頓幀結束、球體射出的那一幀觸發最強震幅，並在擊殺（Get Decked）時加上重度全屏震動與角色碎裂成白色方塊的擊飛特效 `[00:00:58]`。
* **多層次音效與音高遞增（Pitch Scaling）：**
  * **擊球音效分層：** 拆分為「頓幀開始的金屬敲擊聲」、「頓幀期間的低頻電流蓄力嗡鳴聲」與「頓幀結束球體射出的音爆聲」三段。
  * **動態音高：** 隨著每次對抽球速提升，逐步拉高蓄力聲與擊球聲的 Pitch 與失真度（Distortion），配合觀眾歡呼與警報聲 `[00:02:12]`，從聽覺直接放大壓迫感。

## 5. 遊戲引擎實作開發計劃（分階段路線圖）

建議按以下四個階段在引擎（如 Godot 或 Unity）中逐步搭建原型：

### 第一階段：物理迴圈與動態頓幀控制器（第 1 週）
* [ ] 建立全域 `HitstopManager`，負責在擊中時凍結球體與角色的運動邏輯（而非直接將全域 `time_scale` 設為 $0$，以便讓 2D 打擊特效、鏡頭震動與角色 Jitter 仍能以正常 $60\text{ FPS}$ 播放）。
* [ ] 實作球速累加機制與頓幀曲線表（Curve），測試不同球速下的停頓幀數手感與出球角度輸入緩衝（Input Buffer）。

### 第二階段：2D 序列幀特效（Flipbook VFX）管線（第 2 週）
* [ ] 繪製 $4$ 套核心手繪序列幀（每套 $4$ 至 $6$ 幀，$12$ 至 $24\text{ FPS}$）：**揮擊弧光**、**擊中同心圓星芒**、**巨型黑白十字閃光（Impact Frame）**、**落地／彈牆煙塵**。
* [ ] 編寫特效混合 Shader，支援將黑白灰階的手繪特效序列幀透過 `Color Ramp` 或 `Modulate` 動態染成當前擊球角色的代表色。
* [ ] 加入長條狀 Mesh 拖尾組件（Trail / Line2D），根據球體歷史座標與當前球速動態調整寬度與長度。

### 第三階段：Shader 視覺切換與全屏演出（第 3 週）
* [ ] 為角色模型加上受擊反白／單色剪影 Shader 參數（`_FlashAmount`），綁定受擊與硬直狀態。
* [ ] 建立場景主控制器，當球速大於設定閾值時，觸發背景環境壓暗／染紅 Shader，並替換球體本體為高反差黑核貼圖。

### 第四階段：鏡頭、UI 與音效同步調校（第 4 週）
* [ ] 實作方向性鏡頭震動（Camera Trauma System），將震動強度與球速直接掛鉤。
* [ ] 整合速度計 UI 與頓幀讀條，並掛載三段式擊球音效（Hit In / Charge Loop / Release Boom），設定隨球速連動 Audio Pitch。
