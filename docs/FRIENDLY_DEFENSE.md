# 更容易成功的格擋與反擊

2026-11-09。依使用者要求，直接調整預設時機，並提供真實成功回饋；正式對戰、練習及 Demo 使用同一規則，不另加隱藏作弊判定。公開 Web 不更新。

## 玩家現在怎樣用

敵人出手前短按 **Shift**。成功後會見到「完美格擋！J 反擊」及角色上方提示；按 **J** 反擊即可，**繼續按住 Shift 也能出手**，提前按的 J 亦可緩衝。命中才顯示「反擊成功！」；普通防禦成功顯示「擋住了！」。

空中終結招仍按 Shift 反制，成功後有較長時間選 **J 反踢／E 抽身**。F11 → F8 → K 可反覆練，F10 練動能換手，F12 看雙 AI 展示。F2 保留提示與基本成功特效。

反擊機會是操作提示與輸入容錯，**沒有自動出拳、額外傷害或必定命中**。完美格擋仍需正面、護盾及冷卻；太早的短按會過期，投技仍剋防禦；空中仍花 25 能量、每次離地一次，反踢可以被閃避。按住防禦不會不斷重設精準窗口，高階 F10 的連按也不能無限刷新。

## 正回饋的來源

地面成功擋格使用現有硬邊防禦效果／音效；完美格擋加能量、延長可懲罰時間與 J 提示。反擊確認事件只在實際傷害命中時發出，空揮、被擋或失敗不假裝成功。對手完美格擋會顯示「對手擋住了」，不錯把對手成功說成玩家成功。

F10 接住後改為「接得好！按 J 準備反擊」，空中交換標為「反制成功！」；原有成功弧／核心／音色保留。沒有新增全屏長閃光或每次替音樂重開。
