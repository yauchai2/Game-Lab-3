# 場景設計基準

## 最新戰鬥演出方向（2026-11-09）

目前已實作近身格鬥與共用壓力三選，以下「尚未選定戰鬥」是早期場景歷史。新增 [爽感優化計劃](GAME_FEEL_ROADMAP.zh-TW.md) 作為後續規格：接觸／壓縮／釋放、有限格擋換手原型、選角／VS／KO。換手是建議實驗，尚未替換已確認的壓力三選，所有新參數需驗證；不引入球類玩法。

本文件記錄此聊天已確認的方向；沒有假設其他對話的設計結論。

## 目標

以使用者提供的低空客機掠過港式街道照片為構圖參考，建立 Godot 4 風格化可遊走小街區。原照片來自聊天附圖，其 G: 路徑不是本 repo 可存取的檔案；目前 repo 沒有原照片及原始參考影片。七張 AI 資產參考圖已保存在 references/assets/。

第一版包含街道、簡單走路／跳躍／相機、六件現有道具，以及可重設的飛機掠過事件。探索、滑行／跑酷或競技玩法尚未選定，不將完整滑板、戰鬥或交通系統列為已承諾成果。

## 美術分工

| 參考 | 轉譯用途 |
|---|---|
| 原照片 | 左冷右暖街牆、黃框直立招牌、天空缺口、巨大機腹與街道縱深 |

| 使用者提供的 SLUMLORDZ 影片 | 密集店面、棚架、電線、停車及生活細節的分布 |
| Lethal League Blaze | 局部圖形、互動與事件回饋 |
| Nam Mac | 使用者指定方向；原社群連結未另行核對，不推斷上傳影片作者 |

不以固定百分比混合風格。先用純色量體確認四個大形，再精修 10–15 m 街段。現有模型仍使用來源 PBR 材質，最終 toon 外觀待驗收。

## 白盒起點

- 主街長 64 m，道路寬 8 m，兩側人行道各 2 m。
- 樓層約 3.3 m，主建築 4–6 層，保留高低錯落與短側巷。
- 全部尺寸是可調設計參數，不是照片測量結果。
- 固定相機以方形畫幅比對照片，遊戲相機另驗收 16:9。
- 客機先由 AI 程序分件製作白盒，確認機腹與四引擎輪廓，再決定精修方式。
