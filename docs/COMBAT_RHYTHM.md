## 操作與角色

Desktop Pull `codex/street-combat`，Godot 4.6.3 F5。按住 **J** 連段、**K** 挑空／暴扣、**L** 能量爆發；F12 看無限交戰，R 重開、Esc 暫停。**F2** 返回減少演出的 1 倍速版本，可直接比較。

護目鏡的**角色 4** 顯示縮放由 **2.1 → 1.4**，身高是之前 **2/3**；另外三位保持 2.1。原 GLB、骨架與貼圖不改，陰影、骨架殘影粗細、受擊星及出招特效高度跟著調整。四位仍共用招式與碰撞規則，這輪沒有改小模型的傷害／判定能力。

## 節奏分層

`combat_rhythm.gd` 控制雙方共同的遊戲時鐘：停住時判定也停止。原本固定 60Hz 的 simulation 步進保持，按牆鐘時間暫停／減少／增加執行次數，只接真實發招／命中事件。

| 事件 | 全停 | 慢鏡（0.22 倍） | 釋放長度／速度 |
|---|---:|---:|---:|
| 挑空命中 | 0.055s | 0.14s | 0.20s／1.65 倍 |
| 追擊 | 0.025s | 0.035s | 0.17s／1.8 倍 |
| 格擋／空中反制 | 0.12s | 0.18s | 0.24s／1.65 倍 |
| 已付能量的爆發起手 | 0.16s | 0.26s | 0.32s／1.8 倍 |
| 暴扣、爆發或反踢命中 | 0.11s | 0.20s | 0.30s／1.85 倍 |
| 累積重擊 BREAK | 0.18s | 0.24s | 0.36s／2 倍 |

輕拳不另開長慢鏡，維持連打的基礎速度。挑空／追擊有 0.75 秒冷卻，較弱事件不覆寫強演出，同級不重新起算，避免每拳都凍住。每個物理呼叫最多兩次固定步進，遇到新停頓即停止該呼叫的餘下步進，不跳過判定。

停頓期間保留尚未消費的輸入；暫停凍結節奏及紅幕時鐘。F2 恢復每次物理呼叫一步、街景與普通鏡頭；重開／退出清空累積器。新時鐘影響兩方的出招／反制／回合時間，音樂保持原速，不用全域 Engine.time_scale。這輪改了實際對戰節奏，每個 simulation tick 的規則保持。

## 紅幕、全屏圖形與鏡頭

- 爆發起手紅幕 **0.16 → 1.0 秒**；命中紅幕 **0.14 → 0.65 秒**。
- BREAK **0.32 → 1.1 秒**；真 KO **0.64 → 1.2 秒**，結果選單 **1.4 秒**後出現，Enter 仍可跳過。時間到／平手不冒充紅幕 KO。
- 技能偏玫紅、BREAK 偏橙紅、強命中鮮紅。新增八角收束能量環、OVERDRIVE 切入、放大尖星與 12fps 階梯放射背景，保留真正 3D 角色。
- 停住時斜切上下遮幅；慢鏡側邊刻線；釋放時 26 道全屏硬邊放射速度線。移除紅幕技能的重複字卡，慢鏡不在同一位置持續疊骨架殘影。
- 攻擊鏡頭依兩方位置繞行、拉近、上下運動；慢鏡約 44° FOV、釋放約 50°，傾斜最大約 11°，釋放時反向甩鏡／抖動。構圖距離考慮兩人高度與水平距離；普通強震幅度提高，KO 延續獨立近鏡環繞。

參考仍是[兩部影片研究](COMBAT_VISUAL_STUDY.md)的接觸前收束／紅幕留角色／旋轉近鏡等觀察，本輪亦重看已保存的抽幀接觸圖。以上是本作設計參數，不是原遊戲內部時間的量測，未搬入其影像或音效。

## 證據與限制

[驗證紀錄](VALIDATION.md)及[片段時間線／事件](evidence/combat-rhythm/capture.json)。30 秒片段是單一不中斷雙 AI 交戰，固定 60Hz 牆鐘步進、每四步原生擷取一張，450 張／15fps、無音軌。simulation_ticks 依新節奏變化，不等於牆鐘步數。命中由 combat_event signal 計數，避免停頓期間重讀上一 tick 的事件造成重複統計。

Godot Compatibility／軟體 GL／Dummy 音訊，自動檢查與畫面檢視不是人手的爽感／平衡、實聽或目標 GPU 驗收。真人需比較紅幕頻率、甩鏡舒適度與操作時機；F2 可隨時比較。只推來源分支，不更新公開 Web，未操作使用者電腦。
