# S2 基本遊走原型

用 Godot 4.6.3 開啟 `godot/project.godot`，執行主場景 `scenes/street_walk.tscn`。它直接引用 S1 白盒，沒有覆寫原場景或原始 GLB。

## 操作

| 輸入 | 功能 |
|---|---|
| WASD／方向鍵 | 依相機水平方向移動 |
| 滑鼠 | 轉動視角，可抬頭看飛機 |
| Shift | 加速移動 |
| Space | 跳躍，可跳上 0.16 m 人行道 |
| V | 第三人稱／第一人稱切換 |
| 1–5／Tab | 查看 S1 固定視角，停止角色水平輸入 |
| 0 | 回到角色視角，位置保留 |
| R | 重設位置、速度與朝向，回到遊走視角 |
| B | 在原始材質、兩段與三段明暗樣片之間切換 |
| P | 隨時重播飛機掠過事件 |
| C | 在程序分層雲和原純色天空之間切換 |
| N | 在生成的圖片天空與程序雲之間切換 |
| Esc | 釋放游標，停止移動與視角輸入 |
| 滑鼠左鍵 | 在遊走模式重新要求鎖定游標並恢復操作 |

預設第三人稱，使用高 1.75 m 的簡化比例替身；這不是最終角色模型。視窗失焦也會釋放輸入，再點擊即可恢復。掉出場景或低於安全高度時自動回到入口。

## 目前行為

- 步行速度 4.5 m/s，加速速度 7 m/s；重力 20 m/s²、跳躍初速 6 m/s，皆為可調原型參數。
- 移動依水平 yaw 計算，抬頭不會讓角色起飛；斜向輸入經正規化，不增加最高移動速度。
- 使用 CharacterBody3D、膠囊碰撞與地面吸附。碰撞以既有白盒與道具代理為準。
- 第三人稱 SpringArm 長 3.4 m，以球形掃掠靠牆縮短；排除玩家自身碰撞。第一人稱隱藏替身並將相機臂長設為零。
- 垂直視角限制為向下 75°、向上 80°，避免翻轉。
- 目前路緣需要跳上，沒有自動跨階、攀爬、滑行或跑酷；這些留待玩法決策。

## 專案結構

- `godot/scenes/street_walk.tscn`：遊走主場景，組合 Street 與 Player。
- `godot/scenes/actors/test_player.tscn`：碰撞、比例替身、相機臂與相機。
- `godot/scripts/test_player.gd`：移動、跳躍、視角、游標要求及掉落回復。
- `godot/scripts/walk_session.gd`：固定相機與角色相機切換、重設及操作說明。
- S1 的 `street_whitebox.tscn` 與資產對照 `review.tscn` 仍可獨立執行。

## 已驗證

在 Godot 4.6.3 的 headless display driver，以 60 Hz 物理模擬注入輸入並跨實際物理幀測試，28 項檢查通過：

- 起點落地、前進、停止、斜向速度與加速。
- 跳躍落地、跳上人行道、沿主街移動超過 50 m、從人行道進入側巷。
- 建築、停放廂型車及郵箱阻擋角色；不是只確認碰撞節點存在。
- 牆邊相機臂由 3.4 m 縮短至約 0.81 m；僅代表這個測試位置。
- 滑鼠事件處理及俯仰限制、第一／第三人稱切換。
- 固定視角停止角色、Tab 循環、返回角色視角、重設及掉落回復。
- Esc／點擊的游標鎖定要求，以及失焦後的輸入釋放。

證據：[verification.json](evidence/walk/verification.json)、[verification.log](evidence/walk/verification.log)。

重現：

```sh
godot --headless --editor --path godot --import --quit
godot --headless --path godot --fixed-fps 60 --script res://tools/verify_walk.gd
```

60 Hz 是測試模擬設定，不是效能達標結果。無視窗驅動不提供真實游標鎖定；測試區分應用程式的鎖定要求與桌面實際鎖定，不聲稱後者已通過。

- 目標硬體 GPU／效能、最終 toon 材質與飛機事件的人工驗收。S3 已取得 Godot 軟體渲染樣片，見 STYLE_SAMPLE.md。
