# 預告技能的敵人反應與正式遭遇比較

2026-11-16，接續9554491的[第二支援模組](TACTICAL_MODULES.zh-TW.md)。正式STORY的普通敵人開始回應玩家的可見地面預告區；同時補齊入場結束後的構築比較。沒有新增技能、按鍵、存檔欄位或改傷害／生命數值。

## 敵人怎樣讀預告

| 敵人 | 空閒且察覺危險區時的嘗試 | 玩家可利用的限制 |
| --- | --- | --- |
| 雜兵、突進兵、干擾兵 | 選一個離開區域的方向，以普通移動走出去 | 短時間固定方向，仍受身體、邊界與受擊阻擋；近身可壓住路線 |
| 盾衛、隊長 | 短暫架防 | 沒有自動招架；消耗原防禦值，可用原投技或破盾路線處理 |
| 重裝 | 維持原職責與動作 | 沒有新增走位／架防反應，預告技能仍可懲罰較慢承諾 |
| Boss | 維持原階段與反制機制 | 不用普通敵人反應覆蓋頭目腳本 |

- 預告至少顯示8個模擬tick才可被讀取。Easy／Normal／Hard分別每18／12／8tick採樣，依敵人身分錯開；不是每一影格都預知命中。
- 只對尚未爆發、由玩家建立的固定`zone`反應，包括延時支援及工地封條。普通即時脈衝、飛行彈與已結算作用保持原規則。
- 一次反應最多20個指令tick，啟動後180tick冷卻。移動方向在開始時選定，不隨危險區即時轉向；靠牆時可選向內路線。
- 只在地面空閒時開始；攻擊、受擊、空中、已承諾突進與入場期間不取消原動作來閃避。受擊中斷反應但不退冷卻。
- 架防低於足夠防禦值時不啟動，且明確禁止這份反應自動招架。走位使用原速度與碰撞，不添加無敵、跳躍、瞬移或傷害裁決。
- 頭上短暫顯示「走位中／架防中」，只反映當前意圖。靜音狀態提示仍優先。hitstop與暫停會凍結反應；新遭遇使用新角色狀態。

回應由`tactics/enemy_response.gd`決定普通指令，經原`_advance_fighter`移動／格擋。沒有直接扣血、強制落空或改投射物命中集合。等待進攻的隊員亦能察覺區域，但仍不因此取得額外進攻名額。標準FIGHT／Demo及關閉AI的控制fixture不套這項故事反應。

## 28組比較保留成功與失敗

同一個RIVET策略，正常100生命／60初始能量，Normal及Hard三組敵群×四種配置，加兩個Normal頭目×兩種配置，共28組，每組重播一次確認確定性。所有組別都等入場結束才交戰，沒有逐tick補能、改敵人位置／生命或強制命中。

策略使用寬幅返工震線，在近距離空檔優先嘗試；原模組與延時組都用同一變體／防守／出招判斷。回收組與完整蓄力接力組比較，保持主支援一致。每場上限1800次輸入tick，包含hitstop，不能換算作真人通關時間或硬件FPS。

| 入場後遭遇 | 原寬幅震線：結束tick／生命 | 延時寬幅震線：結束tick／生命 | 延時模組真命中數 |
| --- | ---: | ---: | ---: |
| Normal盾衛、雜兵、突進兵 | 534／100 | 588／92 | 1 |
| Hard重裝、突進兵、干擾兵 | 804／90 | 634／91 | 1 |

這些例子表明不是每次改成延時都更快或更安全，但不能由兩列推論全局平衡。完整資料有部分零次戰術施放／零模組命中場次，全部保留；其中完成tick差異可能只是改變出招時序，不能算作該模組的直接效益。

實際測得普通敵人走位與架防各有觸發，也有承諾狀態不能反應的場次。機械頭目組完成時僅剩8生命；訊號頭目組兩配置都失敗，紀錄仍是`failed`，沒有降低Boss規則來取得綠燈。自動策略防守理想化，而且不會完整處理頭目地面機制；不能據此宣稱頭目、完整18場故事或真人樂趣已平衡。

舊首輪策略會在入場緩衝中先放技能，不能覆蓋交戰中的反應；新比較明確等入場結束。近距離策略仍可能直接用基本連段勝出，因此不要求每一場都有戰術施放，只檢查總體確有模組真接觸，且資源／重播／新反應成立。
