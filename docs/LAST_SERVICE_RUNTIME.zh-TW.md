## 操作與專屬玩法

共用 A/D移動、Space跳躍、J連打、K挑空／空中暴扣、Shift防禦、E閃步、G投技。基礎技巧及四角色一開始全部可用。

- **ZIP**：近身閃過一記攻擊得到ROUTE，最多2枚、180 simulation ticks後消失；同一敵人出招只給一次。之後合法E閃步可花1枚換更快移動／較短冷卻，不把剛賺到的標記吃回同一次閃避。L「急件簽收」第一踢真命中後才續第二踢；W+L「末班快送」第一擊真命中才最多續兩擊，每擊仍檢查距離、方向、空中狀態；揮空不全場追蹤。
- **RIVET**：按住L「落鉚」，蓄到PRELOAD I／II再放；第二階加傷害／擊退及防禦壓力，最長36蓄力tick自動釋放。兩階有姿勢／HUD／不同音高提示。霸體只在RIVET指定技能起手最後6 tick，不是四人全程霸體；投技仍能中斷。W+L「停工通知」短距離、38 tick起手、長恢復。
- **HUSH**：一次正面近距離完美格擋取得1份SAMPLE，最多1份、240 tick到期；遠端節點脈衝不給取樣，投技不能用普通招架全解。下一次指定Cross／K／L／W+L花掉取樣，增加位置收益及少量傷害；沒取樣仍可正常用招。L「留白」短後撤直拳；W+L「全場靜音」為短距離強截擊。
- **LOOP**：L放近接點（20能量）；移動鍵＋L放較遠，最多2點，第三點回收最舊。S＋L手動「交叉接線」（10能量、8 tick起手），一點短脈衝、兩點之間短線；放點後可付費取消恢復接脈衝。節點300 tick到期，可被對方正確方向／距離的有效攻擊拆掉；觸發有84 tick冷卻、受擊後不能憑空繼續觸發。W+L「安可迴圈」消耗現有節點作依序脈衝，再保留本體正面打擊；無節點時只有本體收益。

節點脈衝沿真傷害／格擋／招架路徑；與普通攻擊共用同一幀的接觸快照，允許合法同時互打。沒有為動畫加必中、假命中或修改AI血量。AI有RIVET蓄力、HUSH截擊距離、LOOP佈點／觸發等合法輸入策略，Demo仍是自由交戰。

## 街區模式、技能點與解鎖

入口：**FIGHTERS → STREET RUN**。每次3站、每站一局，依序遇其餘三角色；勝利進下一站、敗北結算。AI難度逐站增加至既有上限，不偷偷加敵方血量。返回時恢復原本對手／基礎難度；一般設定保存不把暫時的對手與升階難度寫回偏好。

- 勝利40 XP、敗北15 XP；該站首次出現的格擋／追擊／彈地／拆點，最多3種、每種＋5。重複結算ID不重複發獎，標準FIGHT／訓練／Demo不給XP。
- 每角色獨立熟練度：每40 XP升1級並得1技能點；第一版最高3級，XP記錄上限240。每人3個節點，共12個，依LV1／2／3開放購買，每個1點。
- **FIGHTERS → SKILLS**：解鎖後另選裝備，最多2個；免費重置返還技能點、保留XP。新增保存失敗提示。標準FIGHT移除所有成長修正，街區下一站才套用新裝備。
- 120 XP解鎖該角色 **PALE FX** 淡色效果調色，可自由切換，影響效果／演出色，不偽稱是新衣服模型。
