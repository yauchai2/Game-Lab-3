2026-11-10。整合前輪討論及使用者補充分析，目標是讓首次一分鐘有可操作的爽感，一場對局有清楚的升溫、轉勢、爆發及回氣。**本文件是下一輪實作規格，尚未更改戰鬥runtime或公開Web。**

## A：先讓玩家看懂升溫與回饋

第一切片保留現有pressure取值／衰減及全部真實傷害，讓正式對戰／自由Demo都能讀到SURGE。

| 階段 | 畫面／聲音 | 玩家讀到的意義 |
|---|---|---|
| 0–29／FLOW | 乾淨角色輪廓、短局部火花、清楚中頻拳聲 | 試探距離，建立命中和格擋節奏。 |
| 30–59／HEAT | 角色招式弧線加強、較重音層、背景一次短反應 | 接連交鋒正把局勢推高。 |
| 60–90／SURGE | 明確升階音與一次數字跳動；符合條件的重擊／反制有較強演出 | 高壓機會已到，仍需合法命中及支付原能量。 |

空揮不加壓；LOOP擺點本身不加壓，真脈衝接觸沿既有路徑計一次；同一接觸serial不得重複計分。連段會自然升階，實際擷取後再決定是否需要對同一段落的增壓衰減，避免尚未觀察就同改多項規則。

HUD先試上方計時器下的中央空隙（logical約x556–724、y88–124），與左右角色資源分開。顯示SURGE數值／三階及升階短跳動；普通時候固定，保持12–16內部像素可讀。現有STREET RUN BUILD ON字串移到回合入場／暫停／結算，讓中央資訊有位置。每個提示要分清「起手」「真命中」「擋住」「反制成功」，由Simulation事件驅動。角色配色之外仍標P1／P2歸屬。

A完成不宣稱已有高壓改招、額外傷害或新三選博弈。先驗證玩家是否看懂升溫，並看出低壓與高壓的反差。

## B：把停頓中的輸入變得可靠

先改善既有成功格擋／挑空後的預輸入：J反擊／續攻、K挑空或空中砸地、E追擊或抽身，按角色狀態解析。每邊每次事件最多接受一個有效續行，並顯示已收到的指令；不能靠按鍵重複洗掉另一邊的輸入。按住J不視作每幀重新選一次。

輸入進Simulation後仍檢查硬直、距離、追擊次數與能量；已鎖定只保證記下意圖，不保證命中。被中斷、KO、重開或退出要失效；Esc保留當前有效狀態，暫停時不偷倒數。防守成功必須有立即而清楚的回報，完整反擊成功只在真命中後顯示。

更完整的雙方「高壓轉勢」另做有界原型：僅在雙方仍有行動權的合法近身接觸前開一次窗口；原型起點約0.30–0.40秒，不因按鍵／慢鏡無限延長。判斷和倒數由Simulation的固定決策步進處理，presentation hold不吞掉輸入，UI不裁決勝負。沿用pressure owner並設冷卻；舊F8三選教室繼續隔離，不直接把它塞進每次空中連擊。

此原型需先比較「可靠預輸入已足夠」與「額外決策窗確有樂趣」，再決定是否取代正式流程。不能把受擊硬直中的角色透過新UI瞬間恢復行動，也不給無限免費反制。

## C：用距離與承諾建立真實博弈

一般招式相剋先在現有系統中變清楚：拳腳可截斷尚未成立的投技；投技威脅長按防禦；完美格擋反制可格擋的正面攻擊；退步／跳躍以位置避開近身投技，會受長距離壓迫限制。這些都取決於範圍、起手和當前狀態，不能寫成任何時候都保證成立的三角表。

假動作如新增，必須只有預備段可取消、支付明確代價及保留恢復，不允許active frame後回頭改判定。AI按公開狀態預先承諾，不能讀玩家尚未公開的pending來選剋制答案。新手首站以較明確預備動作／少量招式教讀招，傷害仍走正常規則。

## D：角色與視聽一致

- ZIP：折線位移、踢擊弧、較短脆節拍；ROUTE追擊要看得見起點和終點。
- RIVET：清楚蓄力階段、壓縮姿勢、低頻重量；拳真正生效才放出衝擊。
- HUSH：格擋瞬間收斂、截擊線／換位輪廓、清楚SAMPLE標記。
- LOOP：節點和脈衝路線優先可讀，手勢／接點音與實際節點事件同步。

用3D骨架姿態配分幀手工2D形狀；是否採用sprite sheet按逐招品質決定，不因參考文字就假定原作所有特效的實作方法。背景明度、特效覆蓋、鏡頭方向共同讓雙方輪廓及接觸點可見。強演出後安排回氣，F2保留招式／狀態資訊。

音效分接觸中頻、重量低頻、強度高頻和終結釋放；限同事件層數、保留混音餘量，實錄後查峰值與重複聲疲勞。BGM保持原transport，只平順duck；沒有音樂stems／BPM資料時不承諾自動配樂節拍同步。場景觀眾／燈光只對有冷卻的關鍵事件反應。

## E：首分鐘、三站與故事

首次一分鐘要讓真人能主動完成一次小連段、格擋反擊、追擊與爆發。教學可有明示狀態fixture與提示，自由AI Demo使用正常輸入／判定，不用必中腳本代替玩家體驗。自動測試不能證明新手覺得爽或真的學懂。

現有Street Run三站再作敘事切片：一個角色動機 → 中途路線／本輪選擇 → 有習慣可讀的決戰對手。以短對話、不同入場／勝利pose與少量場景事件連接；完整故事與城市停運設定仍是候選，尚未寫入正式劇情。XP／兩裝備槽／免費重置及標準FIGHT固定數值規則保持。

## 交付次序及驗收

1. **A＋B基礎切片**：SURGE可見、三級回饋、預輸入一次消費、低／高壓停慢快對照；不先加新地圖或更多大招。
2. **一場完整對決**：實錄0壓至高潮再回氣，檢查HUD／角色／音樂與空中追擊，兩組正常AI各30秒，包含低能量、連段失敗、被反制及LOOP拆點。
3. **高壓窗口原型**：固定決策時鐘、公平輸入、超時／中斷／同幀／暫停／重播一致；原型有人手比較後才採入正式。
4. **三站敘事與變化**：以前面可玩的核心擴內容，再做解鎖／勝利動畫的統一包裝。

規則驗證包括揮空／擺點不增壓、同serial不重算、封頂／衰減／重置、窗口有界、無硬直偷跑、能量／距離合法、角色和成長模式隔離。原生驗證包括640×360字體／頭部／接觸點易讀、真按鍵在hold期間被接受、F2／Esc／退出清理、音樂播放頭連續及混音。錄下正常對局與明示fixture並分別標示，保留目標Mac與真人手感待驗範圍。只推開發來源分支；公開試玩更新仍須使用者明確要求。
