# 夜班場：可玩的回城據點

2026-11-12。以使用者確認的黑白工廈／桃紅背景／尖角低模等距概念圖製作。接在最新 main 6fdd3a6 的正式 STORY 城市入口，沿用現有戰役、交易、天賦、角色及存檔；不是背景圖片或另一個展示模式。

## 如何進入

啟動遊戲 → STORY → 夜班場。WASD／方向鍵移動，點地板尋路；接近設施會出現 E／Enter 提示。點選設施或按1–6／下排按鈕，角色會沿可行走路徑走到設施後開頁，沒有遠端扣款或瞬移。手動方向鍵可取消尋路。視窗／天賦開啟時停止走路；Esc先關頁，再按才回標題。新功能不需要付費生成或額外Tripo模型。

## 美術與空間

- 約20×13米，中央留空；後牆高、靠攝影機右牆降為剖面，避免遮住商店／Dealer。45度附近固定正交鏡頭，960×540、nearest、無AA，沿正式遊戲設定。
- 主物料為大塊黑白、灰紫硬邊陰影；桃紅天幕，橙／青／螢光綠標示設施。實體幾何與限定色階shader，不靠寫實鏽斑、發光霧或背景平面偽裝3D。
- 香港味集中在工廈窗格、剪刀閘、外露喉管、兩部冷氣機、「夜班」小門牌、一張膠凳與外賣杯。沒有紅燈籠或大量霓虹字牆。
- 玩家及三位同伴使用正式四英雄GLB與共用骨架動作；更換玩家時同伴重新分配，保持各一位、不出現兩個相同英雄。當前角色工作位暫空。
- 12Hz同伴閒置／靠近轉頭、短手臂招呼、慢轉唱盤／冷氣扇、工作台短火花、貨梯門，以及六章戰利品牆。戰利品只依實際 best>=3/6/9/12/15/18亮起，沒有假解鎖。
- 小對白在互動頁，不擋路強迫播放：RIVET不准血滴到工具；LOOP警告別舔接點；Dealer不設退貨；HUSH嫌腳步不合拍。沿現有英文bitmap UI，未新增配音。
- 場景互動動作皆少於1秒。未新增長過場；後續新劇情動畫每段最多15秒。

## 模組及交付

`nightshift/workshop.gd` 是可重建資產工廠，按Architecture／DJLoft／RivetWorkbench／LoopCircuit／ShopHatch／DealerAlcove／FreightLift／LocalDetails分組。使用同一份高度、障礙和導航資料：樓梯是連續坡面採樣加可見踏板，不能從閣樓側邊直接走上去；尋路也必須經樓梯。

- 遊戲入口：`godot/scripts/combat/city/city_hub.gd`。
- 無存檔美術預覽：打開`godot/scenes/city/nightshift_workshop.tscn`，F6。
- 可在Blender編修的完整場景衍生模型：`godot/assets/city/nightshift_workshop.glb`。包含環境、設施、Dealer與機器；四英雄另由正式roster放入，沒有烘死在地圖中。
- 重建GLB：`godot --headless --path godot --script res://tools/export_nightshift_hub.gd`。GLB以基本unlit材質及duotone貼圖近似runtime，Godot的硬邊著色及互動則以腳本版為準。runtime不重複載入整份GLB。
- 來源概念：`references/nightshift-hub/approved-concept.png`；原始Tripo GLB／內嵌貼圖不變，黑白材質只加在hub instance與衍生GLB。原safe_block.glb保留但不再是此入口的背景。
