## 第一次玩

開啟 Godot 4.6.3 的 `godot/project.godot`，F5 進主選單，Enter 對戰。

| 按鍵 | 正式對戰／自由練習 |
|---|---|
| A / D | 左右移動 |
| **按住 J** | 刺拳 → 交叉拳 → 挑空 → 自動追擊 → 空中拳／踢 → 暴扣；須真實命中、距離合法及有追擊能量 |
| **K** | 地面挑空、空中暴扣；↓＋K 地面重踢仍可用 |
| **L** | 50 能量爆發；開局 60 能量，不需先磨一輪 |
| Shift → J | 友善精準格擋 → 反擊，保留 12 tick 窗口與提示 |
| Space / S | 起跳／空中急降 |
| E / G | 手動追擊或閃避／投技與拆投 |
| F2 / Esc | 減少強演出／暫停 |

一鍵連段仍經正常攻擊起手、判定、傷害和資源。空揮不追人；自動追擊花 20 能量、每次離地一次，三拍浮空與反制出口仍有上限。連段後落地提供 18 tick 逃脫保護，避免按住 J 永久壓住對手。爆發起手會受到傷害但不被普通拳腳打斷，投技可中斷；標準及輕鬆 AI 不精準格擋爆發，挑戰 AI 保留該反應。

正式開局縮為 36 tick，初始距離 3.2m；自由練習重置距離 1.4m。地面連段縮短恢復，空中接觸保留微頓幀，挑空／暴扣／爆發依序拉大停頓。鏡頭平時收近，空戰按兩人包圍盒退開；巨拳／巨腳只在判定生效期放大，碰撞仍依 simulation。

## 無限雙 AI

**F12** 進入，**R** 重新開始，**Esc** 暫停，**F12** 返回。兩個右上按鈕亦可操作；不再有 N 下一章或底部大教學板。玩家出招與練習快捷鍵不接管 AI。

兩位 AI 每 tick 按當前距離、受擊、能量、空中狀態及公開起手選擇合法輸入。偏好挑空追擊、空連暴扣、反踩及爆發，但沒有連技劇本、章節輪換、定時瞬移或中途資源重置。只有進入／手動重開時設初始站位與各 70 能量。Demo 忽略回合時間與 KO，HP 最低 1、非受擊時回復，能量每 tick +0.12，維持自由交戰；這些僅限 Demo，正式對戰照常分勝負。

累積真實傷害負荷達 55 後，暴扣／爆發／空中反踢命中可觸發 **BREAK!**；也處理原本致死的一擊。每人有 180 tick 演出冷卻，不加傷害、不重置位置或結束戰鬥。這是無限模式的重擊高潮，與正式 KO 分開。

## 紅幕與動作

不是整個街景乘上紅色濾鏡：暫時隱藏街景並用相機環境換成平紅幕，保留真正 3D 角色與姿態。原創放射線、黃色尖星、大片刀弧與短字卡配合三種層次：

- 付費技能起手 **0.16 秒**；實際暴扣／技能命中 **0.14 秒**。
- Demo BREAK **0.32 秒**，不結束交戰。
- 正式 KO **0.64 秒**：HUD 退場、近鏡環繞／傾斜、模型展示層分離及尖星，接回街景；結果選單在 **0.82 秒**後出現。這些時間是本作設定，不是量測 LLB 的宣稱。

技能不是每次都保證命中；紅幕起手表示實際消耗能量發招。KO 只接真實勝負。展示偏移不改遊戲位置或傷害。F2 停用紅幕、強變形與強震動；暫停凍結展示時鐘，重開／退出恢復街景、陰影及模型骨骼比例。

主要新增程式是 `rush_agent.gd`（輸入決策）與 `impact_theatre.gd`（演出時鐘／圖形）。現有角色／天空／wev 音樂保留，另加入原創合成挑空與落地聲。沒有直接搬用參考影片圖像／音效，這輪不需 Tripo 或生成圖片。
