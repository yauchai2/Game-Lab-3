# 二段跳與操作手感改善

2026-11-10（香港時間）。直接作用於正式 FIGHT、Street Run、自由練習及共用空中教室，來源 `codex/combat-escalation-next`／PR #6。

- Space 起跳，放開後在空中再按 Space 二段跳；A／D 可改方向，落地恢復一次空中跳躍。
- 第二次起跳立即給 10.5m/s 向上速度，第一跳仍是三 tick 蓄勢與 12.5m/s。上升或下墜都可使用，不花能量。
- 每次離地只可使用一次；不能取消受擊、擋格硬直、攻擊或追擊。攻擊結束後可消費尚未過期的跳躍預輸入。挑空後原有 Space 追跳保持。
- 二段跳可煞停急降，但不補回已使用的急降、追擊、反制或滯空餘量，也不重置連段時間；地面反彈不當作落地回充。
- 修正硬落地吃掉 Space 的情況：8 tick 預輸入在有界 4／8 tick 落地恢復期間保留，恢復後只起跳一次。頓幀原有預輸入保持，長按與作業系統連發不自動觸發二段跳。
- 加入短暫收腿姿態、角色色局部月牙弧、現有聲音池的上揚聲及 DOUBLE JUMP 提示；How to Play／空中提示同步更新。沿用現有鏡頭、音效池、F2 與暫停生命週期。

本輪優化範圍是跳躍輸入可靠性與動作回饋，沒有宣稱量得 FPS 提升。探索用的 `test_player.gd` 是獨立舊白盒控制器，本輪只更改目前正式街鬥的共用 simulation。
