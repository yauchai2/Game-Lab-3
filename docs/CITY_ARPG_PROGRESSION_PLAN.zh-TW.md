# 城市故事ARPG：能力解鎖、天賦樹、刷圖與裝備經濟

2026-11-12，Asia/Hong_Kong。依使用者本輪要求詳細規劃。**本文件是下一階段設計提案，未改主選單、能力判定、掉落、抽裝、城市地圖或存檔。** 現有可玩內容仍是codex/story-waves-m1的三波預覽，不能將下列系統當已完成。

## 1. 建議定位

以目前近身／空連／敵碰敵街鬥為戰鬥核心，加一個輕量但可長玩、可換流派的城市ARPG循環：

故事主選單 → 城市地圖 → 選街區／合約 → 波次戰鬥與Boss → 結算 → 配裝／天賦／抽裝 → 回地圖再出擊。

參考POE2式相連天賦、關鍵節點與詞綴裝備的選擇感，採原創「城市電路／地鐵網」表現。第一版不追求數百節點、十幾貨幣、交易市場或完整裝備製作系統；先讓一張圖能刷、一次成長能改變打法。

四種進度必須分清楚：

| 系統 | 取得方式 | 作用期 | 主要用途 |
|---|---|---|---|
| 基本能力／招式權限 | 保證的故事里程碑／短操作任務 | 永久，帳號共享基本移動權 | 逐步教會二段跳、挑空、追擊、暴扣、大招 |
| 天賦 | 街區等級＋主線獎勵的固定點數 | 各角色有獨立配置，可重配 | 決定破陣、空戰、反制、節點控場等流派 |
| 裝備 | 通關掉落、Boss、回收站抽裝 | 永久物品，可存倉／換角色 | 提供詞綴、互動改變與特製裝備組合 |
| 九種臨時核心晶片 | 休息點／出擊準備 | 下一次出擊的整張地圖 | 當次戰術加成，沿用現有九核心與裝備演出 |

永久能力不靠抽裝，主線也不要求抽中特定裝備才可過關。技能解鎖是成長節奏，天賦／裝備是可選擇的打法。

## 2. 主選單與頁面入口

建議仍維持五個清楚的主選項，將故事模式放第一個、較大的主按鈕：

1. **故事模式**：新遊戲／繼續 → 城市地圖；首次可先選四英雄之一。
2. **角色與配裝**：角色預覽、招式、天賦、三格裝備、背包／倉庫。
3. **自由對戰**：標準FIGHT、原SQUAD、AI Demo子入口。
4. **訓練**：所有基本能力可試用、敵型／連鎖／Boss招式練習。
5. **設定**：原聲音／F2／操作等保持。

此為新主選單提案，覆蓋較早固定FIGHT／FIGHTERS／TRAINING／SETTINGS／AI DEMO五項名稱的規劃；保留五項清楚結構與目前黑白、桃紅、青綠視覺。AI Demo移到自由對戰，不刪掉功能。

故事畫面預設「繼續最近街區」，不要每次重新選角。角色、背包、天賦可由城市安全頁進入，不需要為換裝走一整段3D商店場景。

## 3. 能力漸解鎖：先有樂趣，再分批加深

只對**新建故事進度**啟用能力里程碑。標準FIGHT／訓練／Demo維持完整基本招式；老存檔已擁有的能力不被突然收回。四個英雄開局都有自己的基本L招式／角色資源，不能因漸解鎖變成四個完全一樣的角色。

| 時點 | 保證取得的內容 | 關卡如何教 |
|---|---|---|
| 新遊戲開始 | 移動、普通跳、閃避E、防守／基礎反擊、J地面連段、基本重踢、G投技、基本L與基礎撞體 | 第一波可用重踢把一人撞向另一人，立即交代核心樂趣 |
| 首關完成，目標約首5–10分鐘 | **二段跳**，帳號共享 | 短安全路段／避橫掃示範，再進普通戰鬥；不靠錢、等級或隨機掉落 |
| 第2關前段 | 挑空與對應J第三段派生 | 少量敵人，先挑空再落地，避免直接教完整五段空連 |
| 第2關完成 | 有能量成本的空中追擊 | 操作任務以真命中→追擊判斷，未成功可免費重試，不另卡天賦點 |
| 第3關前段 | 空中終結／暴扣、落點範圍玩法 | 教把空中敵人帶回人群落點，對應之後混合波 |
| 第3關完成／第4關Boss前 | W+L大招與一次角色專屬進階技 | 給一次補滿資源的安全試用，學會付費與恢復風險後打中Boss |
| 後半故事 | 每角色1–2個進階派生／關鍵流派選擇 | 任務給使用權，天賦／裝備決定怎樣強化，不再重鎖基本移動 |

首次解鎖可以有短演示與安全試用，之後不每次動作彈文字。二段跳解鎖後仍沿目前即時動作／弧光／音效回饋，不恢復DOUBLE JUMP常駐字卡。

實作時必須同時約束按鍵、按住J自動派生、追擊預輸入及讀檔回復等入口，不能只把按鈕藏起來。鎖住進階派生時給合理地面招式作替代；關卡在教會能力前不能出現必須用該能力才能避開的主線攻擊／通路。選圖頁提前說明側路所需能力。

## 4. 原創城市電路天賦樹

### 規模與點數

首版目標**48節點**：28個小節點、12個主要節點、4個關鍵天賦、4個角色起點／專屬門戶。從四角色各自起點向共享外圈走，角色起點免費啟用，專屬招式效果仍按角色分類。

街區等級先封頂20：Lv2–20共19點，加六關主線各1點，共25個可分配點。等級本身主要給點數，不另偷偷疊一整套攻擊／血量成長。25點不足以全點，需選路線；路徑連通、重置後不能留下懸空節點。

建議街區XP／等級為帳號共享，四英雄各保存自己的25點配置，切角色不需四次重刷基本成長。角色仍有不同起點、專屬派生與實際操作資源。舊的每角色三階成長要做明確映射／備份遷移，不能直接把舊XP數字當新等級。

### 四條共享方向

| 路線 | 小節點例子 | 主要節點例子 | 關鍵天賦方向／代價 |
|---|---|---|---|
| 破陣 | 少量重擊／guard損耗 | 破盾後下一次撞體更有力；較容易推動已失衡重裝 | 撞體傷害更高，但可連帶目標少1個 |
| 空戰 | 空中資源效率、追擊收益 | 每次離地首次真空中擊倒返少量追擊資源 | 空連更有效，地面重擊收益略降；不無限刷新跳躍／反制 |
| 反制 | guard回復、受擊恢復資源 | 成功parry後下一次合法重擊更容易破重心 | 以反擊累積爆發，主動技能較貴；不自動格擋或延長無敵 |
| 回路 | 有界meter收益、節點期限 | 第一次身體碰撞產生小範圍衝擊 | 擴散能力更強，但連鎖單次傷害下降；AOE共用原命中集合 |

例：一個「人群連鎖」build可走重踢效率→破重心→連鎖目標+1→首次碰撞小範圍衝擊；另一個「反制空戰」build走guard回復→parry後meter→追擊效率→空中終結強化。兩者應在站位、出招時機與資源循環上不同。

### 避免樹只是加數字

- 小節點先以3–5%單項改動為起點，主要節點改互動，關鍵節點有明確取捨。
- 不做一堆必點的「開啟閃避／正常跳躍／防守」路費。
- 不直接堆招架窗口、無敵時長、硬直時長或無限空連；不把基本手感賣成天賦。
- 第一版可設同時一個關鍵天賦，先驗證每個流派；之後再測跨區混搭。
- 前兩關／第一次重配免費，之後保留少量遊戲幣成本或整套免費重置選項；先以鼓勵嘗試為主，不用昂貴洗點懲罰新玩家。
- 天賦頁有縮放／拖曳／已點路徑／可點高亮，右側顯示「現在→點後」的真實改變、已用點及返回角色入口。城市地圖和天賦樹分頁，不能把地理路線與配點連線混成同一張難讀大圖。

### 全局成長上限

數值均待實測，但先定結算原則：普通撞體預設4個追加目標，天賦／裝備共用硬上限先抓6；一次來源的命中集合不因AOE或天賦再開一份。同一個觸發家族只啟動一次，不把同一首次碰撞炸三次。技能、天賦和裝備不能各自獨立加一個無界收益迴圈。

單來源meter收益先設總上限，例如原撞體+4可在build下升到最多+8；不疊成每個人各返一整份大招費用。第一輪不加永久無上限吸血；保留SIPHON有限實際回血與不能復活原則。正式數值必須以合成build跑最壞情況再決定。

## 5. 城市地圖

先做可操作的2D／2.5D城市路線圖，用現有街城風格、地鐵線／電路／電台訊號串六區；不是先造能自由走完整個城市的大開放世界。

| 街區 | 主線戰鬥主題 | 常駐重刷特色 |
|---|---|---|
| 霓虹後巷 | 基本連段、撞體與首個能力解鎖 | 短、低壓、基本錢／材料來源 |
| 閘門街口 | 盾衛、破前排與投技 | 防守／破盾類裝備的定向來源 |
| 高架橋下 | 突進＋干擾、首次較大群戰 | 移動／空戰／回路材料 |
| 貨運廣場 | 重裝與大型中Boss | 重擊／裝甲／破陣特製裝備來源 |
| 封鎖大道 | 混合人海與隊長 | 較高常規收入、連鎖build測試場 |
| 核心回收塔 | 巨獸、弱點與多階段Boss | 高階合約／核心裝備及首次通關獎勵 |

每區先1個主線節點＋1條可重刷路線，第4／6區另有Boss再戰入口；場景可以共用並用不同波次／危險物／入口配置變奏，不把14個節點都當需要14張全新場景。

地圖頁只呈現：可出擊主線、可重刷路線、Boss、休息／回收站與當前位置。點一個節點後右側顯示波數、敵型、建議成長、當次詞綴、獎勵方向、所需能力及入口消耗。不能進場才發現能力不符或被扣票。

完成主線解鎖下一區；等級／裝備不是額外強制刷幾十次的門檻。玩家可以靠操作與基礎配裝推主線。每次結算回城市圖，不退回主標題。

## 6. 刷圖分兩層

### 故事期間：免費重刷街區

每區首次清關後可免費重刷，主要3–5分鐘、3–4波。可選已解鎖難度，給正常錢、素材與裝備；首次主線能力／天賦點獎勵不重發。這是資源歸零後仍可玩的保底入口。

### 通關後：T1–T5街區合約

合約是物品，不另加一種通用貨幣。使用已熟悉的六區場地，生成有限波次組合、1–3個可讀詞綴與對應獎勵。

| 階級 | 敵人與機制 | 重點 |
|---|---|---|
| T1 | 3波、1個詞綴；初版先沿用已驗證同場上限 | 配裝與天賦試跑 |
| T2 | 3–4波，增加一個已學過的支援敵型 | 目標優先次序 |
| T3 | 混合精英／兩個互相配合的詞綴 | 流派完成度與聚怪 |
| T4 | 4–5波、高壓人群／精英 | 更高收益與位置控制 |
| T5 | 精英＋Boss變體，最多3個相容詞綴 | 長期build與Boss考試 |

同場數仍受讀招／目標硬件上限限制，不能每升一Tier就無限加人。增加總波內敵數可以分批。單圖先以3–6分鐘為目標，Boss圖較長。

普通合約通關保底返一張同級合約；更高級用可見機率與明示里程碑取得。Boss／固定挑戰亦能保證晉級，避免純隨機卡圖。合約耗盡時仍可免費刷常駐街區取得新T1。

合約開始才扣一次入口物品；暫停／返回標題可繼續同一個run，不重扣。挑戰合約先給3次嘗試，每次從當波checkpoint重試；用盡次數則失去未結算的加碼／Boss獎勵，已入袋的錢和裝備保留。一般故事仍沿寬鬆波次重試，兩者明示區分。

## 7. 地圖詞綴要考驗打法，不能直接廢掉流派

| 詞綴例子 | 戰鬥改變 | 對應收益／限制 |
|---|---|---|
| 增援封鎖 | 多一組有限增援 | 額外錢；同場上限不加 |
| 盾衛巡邏 | 以1名盾衛替換部分普通兵 | 破盾裝備／材料偏重；不能全場都是盾 |
| 干擾信標 | 插入1名干擾員 | 回路材料；不能與Boss大招同時封死安全區 |
| 重裝貨運 | 多1名重裝精英 | 重擊／裝甲獎勵；仍保留失衡解法 |
| 電流路面 | 有明確預告的局部地面危險 | 較高加碼；一直留可靠安全路線 |
| 回收熱區 | 更多可破壞設備／材料點 | 引導聚怪與站位，不能無限產物 |

不建議第一版放「免疫連鎖」「不能閃避」「全圖不能回復資源」等直接關掉核心玩法的詞綴。HP／傷害可隨Tier適度提高，但不要成倍堆到普通兵變長血條Boss。敵人強度由公開Tier／詞綴決定，不偷偷讀玩家裝備然後同比加血。

## 8. 裝備：先三格，讓每件看得懂

| 裝備格 | 主要詞綴 | 機制用途 |
|---|---|---|
| 護腕 | 重擊、破guard、反擊、撞體效率 | 進攻／反制方向 |
| 鞋底模組 | 移動、空中資源、閃避成功收益 | 走位／空戰方向；不抽基本二段跳權 |
| 腰掛裝置 | 回路、節點、meter及特製觸發 | 流派中心，可沿現有骨盆跟隨模組擴充 |

背包／倉庫為帳號共享，角色各保存配裝。一般詞綴可共用，角色專屬詞綴要明確標明並避免出現在尚未能用的抽裝池。第一版不做完整衣服換裝／十種武器，原GLB保留；先把腰掛、護腕、鞋部光效等有限視覺表現做好。

### 稀有度與詞綴數

- 白：固定底材／基礎效果。
- 藍「改造」：1–2條隨機詞綴。
- 黃「稀有」：3條隨機詞綴。
- 橙「特製」：1條有取捨的招牌機制＋1–2條配套效果。

第一版不要一件物品列十行。裝備比較顯示新／舊兩欄、實際差值與是否改變機制；不以單一綠色總評分替玩家決定，因為範圍與單體傷害可能互換。

### 特製物品例子（原創暫稱）

| 物品 | 特製效果 | 代價／上限 |
|---|---|---|
| 接力護腕 | 擊飛身體保留更多動量，更容易接下一人 | 直接拳擊傷害略降，仍用同一條鏈預算 |
| 沉錨護腕 | 破重心後對重裝更有效、重踢更強 | 連帶目標少1個 |
| 回路鞋底 | 成功閃過公開攻擊後返少量meter | 有冷卻，只計真成功，不因空翻滾產生資源 |
| 廣播底座 | 首次撞體產生短範圍衝擊 | 連鎖單次傷害下降，與同家族天賦不重複爆炸 |

不是每件橙裝都比黃裝高所有數值；它應改變build。必要移動能力、基本招架與主線過關權不放橙裝。

## 9. 遊戲幣、材料與掉落節奏

首版只保留兩種通用資源：

- **街區幣**：結算收入、回收站抽裝、少量重配／基礎升級。
- **回收零件**：分解裝備、定向加工／有限詞綴整理；不在第一版開十種稀有石頭。

初始測試經濟例：普通重刷圖結算120–180幣，一次抽裝100幣；約一張圖能抽1次並留下少量儲蓄。一般圖保底一件可辨識裝備，Boss保底稀有物品／指定池獎勵；首關首次獎勵確保能完成一次抽裝。這些是試作數值，不是已完成或已平衡收益。

賣裝備先以低額返幣（例白5／藍12／黃30），分解給少量零件；同一件選賣或分解，不同時拿兩份。販賣回收額不能高過抽取成本形成無限循環。倉庫滿時進臨時溢出區／結算整理，不直接刪掉剛打到的物品。

小怪不逐個跳一整張裝備卡：戰鬥中自動收幣／材料，波間或結算整批入袋。HUD保持血量、能量、波次與必要目標，金錢／背包／天賦詳細資訊留安全頁。打到稀有物品給短聲光標記，清場後再看。

## 10. THE DEALER抽裝

使用現有NPC／機器／聲音／可跳過演出，分成兩個清楚功能：

1. **回收裝備**：花街區幣抽永久護腕／鞋底／腰掛。
2. **臨時核心晶片**：下一次出擊的戰術加成，沿九核心，但不與永久裝備稀有度混成同一池。

永久裝備抽取先選部位，再按一次確認抽；預覽價格、物品等級範圍、稀有度機率及保底進度。一般詞綴以當前角色／已解鎖能力可用為優先。先不加付費貨幣或商城。

一組可試的機率：白25%、藍55%、黃19%、橙1%。連續9次沒有黃或橙，第10次至少黃；連續39次沒有橙，第40次保證橙。兩個計數器帳號共用、明示且存檔，不因切角色／退出重置。首次完成最終Boss另有確定的特製獎勵方向，不讓招牌build全靠1%運氣。

抽到黃／橙也不保證必然適合當前build，但部位定向、拆解用途、Boss定向池與保底要一起存在，讓每次刷圖都有可衡量進展。第一個真正可選的流派不能要求先抽40次。

重複抽裝可用快速揭曉；新物品／首次特製可播完整演出，保留跳過。普通換裝只更新角色與比較頁，不為每一雙白鞋強播4秒腰側裝備片段。現有腰側動畫可用於核心／腰掛，其他部位需合適短動作。

扣幣、產生物品與寫入背包是同一個可恢復交易，成功保存後才播演出；skip不重抽，退出／崩潰不重扣、不吞物品。只做本機存檔一致性，不增加線上帳號或交易市場。

## 11. 九核心與永久裝備如何共存

建議腰掛外殼是永久裝備，臨時晶片插入同一裝置的獨立槽：畫面共用一個清楚裝置，系統上兩個不同作用期。

本輪城市地圖提案下，臨時晶片改為**下一次出擊整張地圖／全部波次**，結算後清除；這取代上輪故事「跨兩關區段」的提案，因為如今每次出擊可重刷並回城市整理。現行runtime的FIGHT／Demo下一局契約不在本輪改動。

主線休息點可保證給一次晶片機會；重刷時可選是否花有限零件準備一個，不要求每次都買。任何Boss都需能無晶片通關。SIPHON等有界收益以整張圖計，不因每波重新生成角色而回滿額度。死亡重試維持同一次出擊的晶片與已用預算，不重抽。

## 12. 三個明確可追求的build範例

| Build | 能力與天賦 | 裝備／跑圖選擇 | 操作差異 |
|---|---|---|---|
| 人群接力 | 基礎撞體、破重心、共享回路衝擊／目標+1 | 接力護腕／廣播底座，選較多普通兵的街區 | 先聚怪、用重踢找射線，一次處理一組 |
| 反制破陣 | guard回復、parry後meter、重擊失衡 | 沉錨護腕／防守型黃裝，選盾衛／重裝圖 | 先接招再打恢復，以少數強擊打出窗口 |
| 空中回路 | 已解鎖二段跳／追擊／暴扣、空戰效率 | 鞋底模組／節點收益，選長街／混合波 | 改落點、跨群追擊，靠暴扣處理聚集目標 |

四英雄能用共享方向，但自己的起點／招式資源讓完成方式不同；不把所有人換裝後變成同一個自動爆炸角色。所有例子都要保留真命中／距離／能量與已有連鎖去重。

## 13. 存檔、模式隔離與經濟邊界

新Campaign存檔需要版本化：帳號XP／能力旗標／城市解鎖／錢與零件／保底，角色天賦與裝備ID，背包／倉庫，當前合約seed／波次／嘗試數／已入袋獎勵，及已領主線里程碑。

- 舊cfg先備份，能力不倒退，舊技能映射與點數補償要先定表並可預覽，不能靜默清空舊進度。
- 入場、清波入袋、通關、抽裝交易均用唯一run／reward／transaction ID提交；同一次重試不能重發主線獎勵或重扣票。
- 一般重刷每次是新run，照常給收益，不把正常刷圖誤當重複領獎禁止。
- 主線死亡不扣已擁有裝備／已入袋金錢。合約挑戰明示嘗試次數與未結算加碼風險。
- 配點／換裝主要在城市／波間安全頁生效，不允許戰鬥中來回換鞋刷新dash、無敵或回血上限。
- 標準FIGHT、TRAINING、原Demo維持固定／既定規則；Campaign裝備與天賦不能偷偷進入一般對戰。
- 不重演目前M1記憶體checkpoint被當成可退出續玩的情況；讀檔、未完成交易、背包滿、未知版本、損壞主檔及備份恢復皆要驗收。

## 14. 製作順序

**先把一個小循環完整接通，再擴成六區與48節點。** 原故事六關／大型Boss計劃仍存在，這次是新增成長與城市層；大型Boss不因文件出現就算已完成。

| 階段 | 實作範圍 | 完成判準 |
|---|---|---|
| R0 戰鬥基礎驗收 | 試玩現有M1三波／角色／連鎖／鏡頭 | 真人能刻意聚怪與破解盾衛，確認核心戰鬥值得重刷 |
| R1 一區完整小循環 | 主選單STORY、城市3個節點、持久存檔、首個能力任務、錢、單一裝備格與回收站 | 地圖→三波→收益→抽到物品→裝上→同圖再打，可退出繼續且不重扣／重領 |
| R2 Build切片 | 天賦先12–16節點／2條方向、三裝備格、少量詞綴／4件特製、免費重刷 | 至少兩種操作上不同而非只差DPS的build；無指定橙裝也能推主線 |
| R3 城市與戰鬥擴充 | 擴六區、完整能力節奏、48節點、中Boss／最終巨獸與T1–T3合約 | 六關可完整推進，成長／相機／弱點／獎勵彼此相容 |
| R4 長期平衡 | T4–T5、保底／經濟／掉落過濾、畫面與目標機器 | 收益速度合理，沒有無限連鎖／回血／免費重抽；人海與Boss仍可讀 |

R1先用一區／三個地圖節點共用現有街景，不要求先畫整座城市或製作一百件裝備。Boss白盒依原戰鬥計劃接入；新Tripo資產仍先給參考圖／分件規格，由使用者生成，不覆寫來源模型。

## 15. 需要驗證的指標

- 首5–10分鐘取得二段跳，第一關已能做一次有意識連鎖；不是靠掉落才開始好玩。
- 每次普通圖能負擔約一次抽裝，5–10張圖內有明確可用改進；不能保證每次全身升級，也不能十張圖完全無進展。
- 新玩家不因錯配點被卡死；第一個關鍵build不用傳奇，四英雄均能普通裝推完故事。
- 合成最強裝備＋天賦＋九晶片，仍受同來源命中／目標／資源／回血上限，Boss沒有被一條錯誤重複事件瞬間清空。
- 市場／抽裝機率、保底與扣款一致；滿背包／skip／退出／讀檔後物品及錢不遺失、不重複。
- 地圖詞綴相容表、可用能力與Boss安全區不互相矛盾；畫外攻擊與文字洪流不因刷圖回來。
- 對局HUD保持簡潔；比較裝備／配點能讀出真實取捨，不需戰鬥中讀六排新數字。
