# 夜班場：按原圖重做與15秒動態

2026-11-12。使用者明確指出上一版與原圖差距大，要求按指定圖片重做、不要加不相關物件，並提供15.083秒影片要求重製動態。本文件取代NIGHTSHIFT_HUB的場景美術現況；上一版證據保留為歷史。

## 做法與範圍，先說清楚

此版採**固定鏡頭2.5D／3D混合場景**：原圖製成去人物的空場貼圖，投影到固定攝影機對齊的地面、立面與深度片；四英雄使用既有真正骨架模型，另有3D Dealer、機械臂、光束、地面光斑、煙與電光。玩家仍在3D座標中行走、經樓梯上閣樓、到實體區域按E互動，並沿用原戰役／商店／存檔。

這是為了保留原圖的構圖、招牌、家具與黑白圖案，不再用一批大概相似的方塊替代。**它不是可任意轉鏡頭的全角度建築模型**；預設鏡頭以外的外觀不保證。原圖人物是生成插畫，現有GLB的臉、衣褶、姿態與比例仍有差異，不能把本版說成逐像素／逐來源幀100%一致。

## 按圖保留／刪除

保留左DJ台與音箱／沙發／樓梯／欄杆／下方箱子，後牆工具板／橙虎鉗／活動橙色臂，桃紅販售窗口／窗內剪影，黑衣Dealer／三輪機器，冷氣機／剪刀閘，「夜班」牌，前右貨梯／青色箭頭，以及小紅凳／白飲品杯、黑色地面閃電與遠處工廈電線。

刪除上一版另加的技能接線大機、章節戰利品牆、地面彩色站位框、工作台四彩抽屜與不符原圖的附加佈置。天賦功能移到LOOP所在區域，保留功能但不新加機器。HUD預設收起，Tab展開操作列及資源，靠近仍出現E提示；開啟交易頁時顯示資源。

## 影片動作時間表

影片來源見references/nightshift-hub/video，15.083333秒／1344×768／24fps。本輪按全時間範圍4fps接觸表及8秒大圖分析，未逐來源幀觀看或實聽原音。以下是手工程序重演，不是把影片貼到場景播放。

| 時間 | 引擎實作 |
|---|---|
| 0–1.2s | 從原圖明亮配色轉入夜色，窗格變青，三束射燈開始掃地。 |
| 0–15s | HUSH交替舉手／操作唱盤，唱盤轉動；RIVET手臂動作及橙色兩段機械臂來回；ZIP招手、放手、擺動再招手。 |
| 約5–7s | LOOP由蹲姿起身，NPC移向機器；玩家若操控LOOP則不被強迫移動。 |
| 約5–15s | 上方管口出少量低模白煙。 |
| 約7.5–13s | 閘門開口變化；貨梯出現桃紅內光與黑色剪影，之後恢復。 |
| 約9–12.6s | 機器附近有有界黃綠電弧，LOOP參與動作。 |
| 約12.4–15s | LOOP回原位置，光束與人物節拍持續。 |

遊戲內進場轉暗只發生一次，之後15秒循環人物與效果，避免每15秒整場白閃。離開城停止渲染／動畫；F2關強光束、煙、電光，保留可用場景。當前背景音樂沿既有遊戲音樂系統，沒有用附件音軌覆蓋。

**交付影片preview-15s.mp4為450幀／30fps，影音皆15.000秒。** Movie Writer原始458幀包含啟動／退出，已裁掉；預覽配上既有menu.ogg低音量，不是參考片音軌，也不是目標硬體即時FPS證明。

## Tripo到底需不需要？

**目前固定鏡頭版本沒有必須由你生成的物件。** 建築、地面圖案與標牌可用投影材質；活動臂、門、光、煙用可控幾何；四英雄與Dealer都有既有GLB。不要把整張地圖丟Tripo重新生成。

若你之後要求所有物件能自由轉鏡頭觀看，或人物外形也精確貼插畫，可用下列優先清單。Tripo生成仍須修模、對尺寸與綁骨，不能保證單次生成完全一致。

| 優先 | 可協助生成的單件 | 規格／分件 | 現在是否阻塞 |
|---|---|---|---|
| 1 | 黑衣Dealer外觀精修 | 圖中黑色高領／尖髮／白色面罩；全身A-pose，無機器，手掌分開，目標65骨人形重綁。原Tripo可先用。 | 否 |
| 2 | ZIP／RIVET／HUSH／LOOP外形精修（每人一件） | 先與現有四GLB比較；只在明確要改頭髮、巨鞋、手套與衣褶時重做。全身A-pose、四肢不重疊，保留原服裝／配色，不加飾物。需新綁骨與動作重定向。 | 否；現有模型已可玩，精確輪廓尚有差異 |
| 3 | DJ台外殼及兩音箱 | 台約3×1×1m，音箱各0.8×0.8×1.8m；唱盤／推桿／喇叭紙盆獨立。不要把HUSH一起生成。 | 否 |
| 4 | 三輪機器外殼 | 寬約2.4、高2.2、深0.8m；黑白外殼、青邊、桃紅槽，三個輪盤留空，另做轉動件。原Tripo不覆寫。 | 否 |
| 5 | 沙發／箱子 | 分開單件，無角色、無背景、無烘焙陰影；約2m沙發與0.8m箱子。 | 否 |
| 不建議 | 地板、牆、樓梯、扶手、閘門、貨梯、機械臂、UI／文字 | 必須準確尺寸、碰撞及活動分件；手工幾何較可控，文字保持獨立材質。 | 不需要Tripo |

共通交件：一個物件一個GLB、原點底部中心、Y向上、正面+Z、真實單位；低面硬邊、少量平色材質、保留貼圖，無烘焙燈光與地面。人物建議2k–8k三角面，主要設施0.5k–3k；只是目標預算，進引擎後再量測。每件先做對應前／側／背設計，再生成，不能從整張場景憑空推定背面。
