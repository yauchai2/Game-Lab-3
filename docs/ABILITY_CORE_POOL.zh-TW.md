# 九種抽獎能力與 AI Demo 自動節奏

2026-11-11，依使用者最新要求實作。這份文件覆蓋上一輪「Demo 也必須手動抽取／領取」契約；上一輪文件及證據保留為歷史。

## Demo 節奏

蒙面人拖機進場 2.05 秒 → 展示代幣 **3 秒** → 自動抽獎 2.20 秒 → 展示結果 **3.5 秒** → 自動領取並進第三回合。約 10.75 秒再接下一回合開場；幀邊界可有小幅量化差異。

Demo 等待頁只加簡短 `AUTO IN 3` 倒數，仍可先按 DRAW／CONTINUE。暫停與設定會凍結倒數；長按接受鍵不會卡住自動展示。正常 FIGHT／Street Run 沒有自動計時抽取或領取，維持放鍵及 160ms 的防穿透。

## 已加入的獎池

每次等機率抽一種，共九種，各約 **11.11%**。沒有稀有度／保底／付費；結果在確認抽獎時鎖定，跳過動畫不重抽。正常第二回合 1:1、Street Run 第二站勝出後的入口保持；兩勝直落沒有額外抽獎。

| 核心 | 視覺 | 實際效果 | 玩法用途 |
|---|---|---|---|
| SPEED 速度 | 青綠閃電 | 移動速度 +20%、衝刺速度 +10% | 追擊、拉距離；不是增加最高速前的加速度 |
| GUARD 防守 | 金黃盾牌 | guard 自然回復 +35% | 減輕持續攻防壓力；不加招架窗口或自動防禦 |
| CHARGE 充能 | 桃紅拳頭 | 下一局開場能量 +20，上限 100 | 立即取得技能資源 |
| **FURY 狂怒（新增）** | 橙紅爆裂閃電 | 真正命中的傷害 +15% | 進攻；沿用原連段衰減及反擊倍率，不改命中／硬直 |
| **PLATE 裝甲（新增）** | 藍色護甲 | 承受命中傷害 -15% | 容錯；不提供無敵或霸體 |
| **FLOW 循環（新增）** | 冰藍循環箭頭 | 命中帶來的攻擊方能量 +30% | 連續進攻換取技能；擋格／招架不給這份額外能量 |
| **ECO 節能（新增）** | 螢光綠電池 | 技能能量消耗 -20% | 一般技能 50→40、超必殺 75→60；LOOP 放置 20→16、脈衝 10→8 |
| **BREACH 破盾（新增）** | 橙色裂盾 | 對擋格造成的 guard 損耗 +25% | 對付龜防；不穿過招架、不添加生命 chip 傷害 |
| **SIPHON 汲取（新增）** | 紫色醫療能量滴 | 每次真命中回 2 HP，整局最多實際回 12 HP | 有限續航；不超過 100、不因擋格／招架回血、不能復活 KO |

所有效果只屬於抽到後的 **下一局**。一個暫時核心、不堆疊；重置／下一局建立新 fighter dictionary 時移除，也不寫入角色 XP／永久裝備存檔。Demo 沿用原本只給 P1 的領取對象。傷害倍率在現有連段／反擊計算後套用，再整數取整；實際每一下的百分比可能因取整有小幅差異。FLOW 只加命中收益，不加開場能量、受擊收益或角色專屬 perk refund；ECO 只減 special／overdrive／node_pulse，不減追擊、受身或空中反制的消耗。SIPHON 滿血不浪費回血上限，只扣實際回復量。

## 演出及遊戲資訊

九種皆有原創硬邊像素圖示、獨立核心色、對應獎品字卡與輪盤停靠圖案，沒有用同一閃電冒充所有結果。沿用每輪四格的可讀大小：初始三格為原閃電／盾／拳，背面的第四格換成本次結果；轉動前的可見圖案不突然跳換。三個輪盤各停在本次核心上，揭曉前的安靜拍不提早出 JACKPOT 或漫畫射線。

結果頁仍使用全遊戲共用 bitmap 字體。戰鬥 HUD 顯示當局核心圖示／名稱，SIPHON 顯示剩餘回復額度。ECO 的真技能門檻由同一 `skill_cost` 提供給扣費、AI 決策和能量條刻度，避免只有玩家扣費改了而 AI 仍等到舊能量數值。

程式：`ability_draw/rewards.gd` 管獎池與領取，`fight_simulation.gd` 管正式戰鬥效果，`cinematic/ability_draw.gd` 管 Demo 局部等待時鐘，`visuals.gd` 管輪盤／獎品，`fight_hud.gd`／`ui/reference_art.gd` 管 active core／刻度。圖示可用 `python tools/build_ability_core_art.py` 重建，來源及 SHA 在 `assets/ability_draw/pool/manifest.json`。原圖、Tripo GLB、音軌都保留。

## 驗證與限制

[九核心原生畫面、Demo 有聲錄像及日誌](evidence/ability-draw/expanded-pool/README.md)。75 能力規則、67 回合／輸入流程、19 九核心原生畫面、22 原模型、34 基本戰鬥、46 四角色／成長回歸，共 **263 項通過**。九核心可達、一次領取及重置、四角色實際命中／扣費、AI 節能門檻、回血上限、Demo 暫停前後自動等待等都有固定 fixture；原生畫面逐個檢視。
