# 雙 AI 技巧 Demo

2026-11-09。依使用者「兩個 AI 自動戰鬥，做出所有技巧」加入原生技巧展示；只更新 `codex/street-combat`，公開 Web 不變。

## 操作

主選單按 **F12** 或點 **AI 技巧展示**。兩位 AI 自動操作，23 段依序播放、決勝後自動循環，不需玩家按攻擊鍵。

- **N／下一段**：跳到下一個技巧。
- **R／重播**：從第一段重新開始。
- **Esc**：暫停／繼續；設定及招式頁同樣暫停。
- **F12／結束**：返回主選單。
- **F2**：減少閃光／變形／震動；M／F4 與音量設定仍可用。

Demo 中 J／K／G／Shift／E／方向／跳躍及練習快捷鍵不接管任何一方；F9 原有數據功能在普通練習保持，未挪用。右下 N／R／F12 為原生可點按控制。離開後恢復原陪練偏好，正常對戰仍由玩家控制第一位角色。

## 展示內容

| 段落 | 實際展示 |
| --- | --- |
| 1–4 | 地面三連、重擊、防禦、破防 |
| 5–9 | 完美格擋、投技、拆投、閃避、能量技 |
| 10–12 | 高壓三選：頂進／卸勢／抽身 |
| 13–15 | 起跳／急降、挑空→曲線追擊→空中三連、暴扣→地面反彈 |
| 16–18 | 空中反制→反踢、反制→抽身、對反踢的閃避 |
| 19–21 | 撞牆反彈、場邊受身、四階動能換手 |
| 22–23 | 雙 AI 自由交戰、能量技 KO 與真實結果演出 |

普通技巧約 3 秒一段，換手段約 4 秒，自由交戰約 15 秒；實際遇交鋒時會待有界交鋒結束才換段。最後 KO 演出約 2.5 秒後進下一輪，左右主攻角色在下一輪互換。畫面顯示 AI 1／AI 2、段名、進度和自動示範標示。

這是**有預設情境的 AI 技巧展示**，並非聲稱兩個通用競技 AI 已自然學會每招。每段開場預設站位／能量；空中反制從空中尾段姿態開始，破防從低護盾開始，高壓段從高壓開始，KO 段從 24HP 開始。這些設定只在切段時發生，沒有在交手途中改位置、硬填命中、直接扣血或注入假事件。兩個決策器透過現有 simulation 輸入完成動作，命中／防禦／距離／資源與退出仍由同一規則計算。

自由交戰段使用讀取公開狀態的走位、出招、格擋、追擊及受身策略；技巧段的反制選擇依該段目標預先決定，不讀取對手的待送輸入。這輪的覆蓋指目前已實作的技巧，不含仍待做的持鍵蓄力、選角或新武器。

## 清理與音樂

切段、重播和退出清除待送按鍵、效果、定格核心、鏡頭反衝與活動音效；音樂維持原播放頭，使用 wev《family ties (wev edit)》，不每段重播。暫停會停止兩位 AI 的時間。HUD 隱藏玩家反制／三選按鈕，只顯示 Demo 控制；F2 保留基本姿態與段名。
