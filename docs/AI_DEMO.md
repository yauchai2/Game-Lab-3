# 無限雙 AI Demo

最新需求已取代原本 23 段技巧展示。**F12** 開始真正連續的雙 AI 交戰，不會倒數完結、KO 重開、切章或定時重設站位。兩位 AI 使用同一套合法輸入與命中規則，偏好挑空、追擊、空連、反踩和爆發；模式專用回復維持戰鬥。

**R** 重開、**Esc** 暫停、**F12** 返回、**F2** 減少演出。右上只有重開／退出；N 無功能。玩家攻擊／練習鍵不控制任一 AI，離開恢復陪練偏好。大招與累積重擊有紅幕，無限模式顯示 BREAK，正式回合才顯示 KO。
