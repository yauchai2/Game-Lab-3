## 開始試玩

1. 使用 `codex/story-onboarding` 分支，Godot開 `godot/project.godot`，主選單選STORY。
2. 所有原基本操作仍從第一場可用。完成第一場自動學第一個戰術技，完成第一區（三場）學第二招與裝備配方；舊檔按best直接取得相應權限。
3. 結算會顯示學招通知與「前往技能設施」。據點SKILLS可以免費改變體／支援、交換兩槽；選擇在下次出擊使用。第一招預設Q，第二招I。
4. RIVET按住戰術槽中的衝鉚彈可蓄壓，放開施放；Shift或E可在蓄壓期間取消，已花費用不退還。普通J持鍵連段與原L蓄力維持各自規則。
5. Esc暫停選單可開操作說明。H已解除戰鬥與據點快捷鍵，據點仍有可點的故事指南。

## 變體、支援、裝備

- 每招提供集中／擴散或角色特定變體。ZIP回郵標可換寬標記但持續減半；折角踢可換短步低傷橫掃，最多接觸三人。LOOP可換快投近點但接點壽命短，或低傷寬脈衝。RIVET／HUSH的寬作用犧牲射程及傷害。
- 每招先有一個支援選擇：接力在真命中後提供下一次近戰一次4能量返還；LOOP設點以成功布置開接力，仍要真近戰命中才返能。RIVET／HUSH第一招可換穿透，傷害降低；其他招可換輕量，冷卻減25%但傷害降低，接點亦縮短壽命。
- 第一區後可在SKILLS定向製作兩件裝備，各30信用點＋3零件，放進背包，到SHOP穿戴。不是隨機抽到才可用。
- **接力電池**：戰術傷害減20%，接力後的那一次近戰返能改6。
- **定錨護腕**：延長投射／接點壽命；ZIP標記更久，LOOP脈衝較寬且起手較長，代價是冷卻增加25%。兩件同穿時只啟用接力機制，介面明示優先規則。
- 沿原三裝備槽、48／25天賦與故事傷害上限。技能升級、既有裝備／天賦傷害、防禦及護盾壓力仍經同一結算路徑；不另建無上限乘算傷害。

## 輸入與安全

鍵盤戰術槽可在設定中從Q／I／U／V／逗號／句號選擇；選到另一槽的鍵會交換。這是兩槽的受限重綁，沒有宣稱全部動作任意重綁。HUD與技能頁取當前真binding。

單人手柄以R3／L3兩個按下搖桿動作使用戰術槽；保留原B／上B招牌、大招與十字鍵移動。實體手柄舒適度尚待驗證；不是已完成手柄人體工學定案。雙人同鍵盤與標準FIGHT不啟用故事新技，所以不搶P2原有I閃避。

消耗技只讀新按下，不讀鍵盤echo重複施放。明確大招、戰術A、戰術B、普通攻擊有穩定優先序，按住J不覆寫已緩衝的新技能。戰術緩衝6tick，只有真命中的jab／cross有明示轉接；不允許揮空或被擋任意取消。

RIVET蓄力走模擬時鐘，hitstop不加速。被打斷不能發射；暫停／失焦會取消尚在蓄壓的動作並清持鍵，已飛出的投射物隨模擬凍結。普通技能的已承諾起手／恢復不靠暫停跳過。退出、換模式、重開與波次重設會清飛行物；所有作用有數量、時間與命中上限。
