# 街區標記收集（企劃 G1 第一批）

2026-11-11。在標準 FIGHT 贏得特定成就會解鎖「街區標記」：8 塊無文字的噴漆告示板立在路緣，每塊一種配色圖形。純演出＋本機存檔，不改判定、傷害或音樂。

## 8 個標記與條件（只在標準 FIGHT；練習、Demo、Street Run、教學不算）
| 標記 | 條件 |
|---|---|
| ZIP／RIVET／HUSH／LOOP 標記 | 用該角色贏下一場對戰 |
| 鏡像戰紀念 | 完成一場同角色對戰（勝負皆可） |
| 同一人連勝五場 | 對同一對手角色連勝 5 場（沿用 [BANTER](BANTER.zh-TW.md) 的連勝記憶） |
| 黃昏以外的勝利 | 在非白晝時段（[時段預設](TIME_OF_DAY.zh-TW.md)）贏一場 |
| 一回合未失 | 贏下對戰且對手一回合都沒贏 |

結算頁會列出「NEW TAG: …」與「TAGS n / 8」。存檔 `tags.cfg` 與 options 同資料夾（版本 1，未知版本或非法 id 忽略）。
