# 原生3D街城標題動畫

2026-11-10，使用者要求模仿TR3B影片的動畫／畫面效果。此次參考：LaGaNga全6.315秒以2fps抽樣，GanGA全21.099秒以1fps抽樣並檢視接觸圖；不是逐來源幀分析。兩份新附檔與既有歸檔SHA相同，來源及具體觀察見 [motion-sources.json](../references/cover-neon-city-2026-11-10/motion-sources.json)。

主選單右側現在是一個真正3D場景，取代靜態海報作預設。ZIP／HUSH使用原GLB及既有52骨重定向動畫，整個人物純青／桃紅剪影，隱去五官及衣服圖案；疊加放鬆擺動、分拍抬手和不同肩線。黑白樓群、窗台、電線和斑馬線是真幾何，鏡頭變位有真實視差。深桃紅天空刻意與前景粉紅人物分開，避免輪廓融在一起。沒有複製參考影片或Blender編輯器介面進遊戲。

循環為8秒、四段各2秒：中景 → 推近 → 較寬景 → 回近景。鏡頭有小幅平移、斜鏡及拍點推近；人物與鏡頭每秒最多更新12次，以停格和快速重新構圖營造節奏。0.5秒拍點是自訂演出時間，不是自動分析歌曲或保證跟兩首音樂BPM同步。Logo、文字、按鈕和提示固定，不跟著攝影機搖動。

`ui/title_motion.gd`擁有唯一376×360、無AA的獨立SubViewport，畫在logical右側528–1280區域，與640×360主畫面共用像素格。兩個人物、三組靜態MultiMesh批次，沒有每拍生成／銷毀物件。離開主選單立即停渲、停時鐘；回來接續。F2減少特效則停用動畫並顯示上一版靜態海報。整套動畫不使用Engine.time_scale、不控制音樂transport，也不改戰鬥判定。

已完成8項動態場景／生命週期檢查及37項既有介面／音樂回歸。完整8秒循環由實際Godot畫面錄成GIF及MP4，並非生成的假遊戲片。[預覽及驗證範圍](evidence/title-motion/README.md)。Linux Godot4.7.2 Compatibility／Mesa llvmpipe；12Hz是更新預算，錄像是虛擬時間擷取，不宣稱目標Mac達到特定FPS。公開Web未更新。
