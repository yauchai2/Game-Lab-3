# 第二支援槽：回收與延時

2026-11-16，接續d26f537的[就緒提示](TACTICAL_USABILITY.zh-TW.md)與[24招選擇池](TACTICAL_EXPANSION.zh-TW.md)。本輪接入**每招可選的第二支援槽**，先提供兩種有明確適用範圍的行為模組；沒有將原八種候選全部當作完成。

## 怎樣配裝

進STORY據點的SKILLS，選好兩招後，各招的原變體／接力、穿透或輕量支援下方，多一個「第二支援」選擇器。可免費留空或卸下，沒有新增戰鬥按鍵。不相容的選項會停用，滑入下拉選項會說明原因；選中的模組下方顯示效果與代價。

| 第二支援 | 適用技能 | 操作變化與代價 |
| --- | --- | --- |
| 回收 | ZIP回郵標、RIVET衝鉚彈、HUSH斷拍線 | 一條真實去程與返程；去程最多接觸一人，返程最多另一人，同一身體整發最多一次。傷害減30%、破盾壓力減20%、去程只走原壽命的一半。邊界可提早折返，不自動追蹤。 |
| 延時 | RIVET返工震線、LOOP遙控混音 | 變為固定地面區，24個模擬tick預告後只爆發一次。傷害減15%，換較闊範圍；敵人可離開或跳過。沒有移動追擊彈。 |

回收與RIVET／HUSH的穿透改變同一份命中預算，所以禁止並用，兩種裝配順序都拒絕且保持原配置。ZIP的輕量仍可與回收並用。其他招式目前只能選「不裝模組」，介面明示適用條件，沒有替拳頭、抓技或所有大招硬套返程。

延時保留寬幅變體的範圍差異：RIVET固定區半徑1.35，寬幅1.9，錨定再加0.25；LOOP在原節點脈衝半徑上增加25%。變體、原支援及裝備的費用／冷卻／威力取捨仍照原順序計算；RIVET寬幅、輕量、延時同用會明顯犧牲傷害。普通主支援仍只有一個，第二支援是另一種可選變形，沒有多放一顆純增傷項。

## 判定與資源限制

- 透過同一`tactics`投射物及原`_resolve_hit`裁決；去返、警告、實際爆發皆由模擬擁有。顯示層只讀資料。
- 回收整發共用同一命中集合、最多兩人、原壽命與原費用，不生成子彈或遞迴分裂。格擋、招架及Boss規則保持；同一Boss不吃兩次。
- 同一回收彈只能啟用一次接力回能。若去程後已近戰取走收益，返程不能重新啟用或延長它。遠端命中本身不逐人補能，反擊強化亦不複製到第二人。
- 延時在起手完成後標示固定位置，不跟隨敵人；24tick後一個接觸tick即清除，沒有人踏入也結束。警告期不播假爆發、不先扣敵血。
- LOOP消耗原有一至兩點後才轉區，不複製節點，最多沿用原兩個脈衝預算。同一區域每個人只記一次，原每節點命中上限保持；重疊兩點仍受原兩點上限。
- hitstop不推進警告／返程，原暫停、重開、離開故事與角色死亡清理保持。標準FIGHT／Demo不啟用故事支援。
