# Nightshift hub environment

`nightshift_workshop.glb` is a derived export of `scripts/combat/city/nightshift/workshop.gd`, rebuilt using `tools/export_nightshift_hub.gd`. It contains the grouped environment and the two existing user-supplied Tripo source models through instance-only duotone materials. No source GLB is modified. Playable navigation, UI, actors and animations are driven by CityHub and the workshop script, not baked into this asset. `scenes/city/nightshift_workshop.tscn` is the F6 art preview. See docs/NIGHTSHIFT_HUB.zh-TW.md for controls, dimensions and limits.
