# 《Lethal League Blaze》戰鬥打擊感與視覺特效深度技術拆解與開發計劃

要重現《Lethal League Blaze》（以下簡稱 LLB）極具爆發力的街頭嘻哈與日式作畫（Sakuga）混合打擊感（參考對戰影片：https://www.youtube.com/watch?v=lEy9hTvaf0s ，對戰雙方為 **P1 紅色隊伍 Jet** vs **P2 藍色隊伍 Candyman**，場景為 **Theodor's Sewage**），核心在於將 **3D 賽璐珞角色與場景**、**純手繪零柔邊 2D 序列幀特效（Flipbook VFX）**、**隨球速非線性成長的頓幀系統（Hitstop / Hitlag）** 以及 **全畫面高反差領域切換（Eclipse Mode）** 深度綁定。

---

## 1. 視覺與渲染底層架構（3D 混合 2D 街頭賽璐珞風格）

LLB 採用「3D 模型模擬 2D 手繪動畫」的渲染管線，所有視覺設計皆服務於一個核心目標：**在球速高達每秒數百單位時，確保球體、角色狀態與攻擊判定的瞬間可讀性（Readability）**。

### 1.1 角色 Shader 與輪廓處理
* **雙階硬邊賽璐珞（2-Tone Cel Shading）：** 角色材質不使用平滑漸層，而是透過 `step(threshold, NdotL)` 將光影強制一刀切為「固有亮色」與「高彩度暗部色塊」。搭配極窄的硬邊邊緣光（Hard Rim Light），在暗色背景中勾勒立體感 `[00:00:04]`。
* **背面法線外擴黑線（Inverted Hull Outline）：** 外框線採用纯黑（`#000000`），且針對攝影機距離進行寬度補償，確保角色無論在跳躍遠離或近景時，外框線皆維持穩定的 $2\text{px}$ 至 $3\text{px}$ 視覺粗細。
* **有限動畫幀率模擬（Stepped Animation Sampling）：** 雖然遊戲物理與位移以 $60\text{ FPS}$ 運行，但角色的骨骼動畫（揮擊、準備姿勢、跳舞嘲諷）採用 **Stepped Tangent（階梯曲線）** 或鎖定於 $12\text{ FPS} \sim 24\text{ FPS}$ 抽幀播放，直接取消補間（Interpolation），讓 3D 角色從預備動作瞬間「跳切（Snap）」到極限揮擊姿勢，重現日本動畫原畫張力 `[00:00:07]`。
* **受擊與硬直的純色反閃（Unlit Solid Flash）：**
  * 當角色被高速球正面擊中（Get Decked）的瞬間，角色 Shader 強制覆蓋 `_FlashOverride = 1.0`，將全身材質（含貼圖）轉為 **Unlit 純白色塊（`#FFFFFF`）** 搭配粗黑邊框，持續至被擊飛撞牆為止 `[00:00:15]`、`[00:00:58]`。
  * 當角色被 Smash（跳起下扣）擊中地面產生彈地硬直時，全身會以高頻率（每 $2$ 幀切換一次）在「固有色」與「純白／亮黃」之間閃爍，提示處於無防禦硬直狀態 `[00:00:34]`。

### 1.2 場景光影與圖層分離（Z-Sorting & Layering）
* **背景低對比壓制：** 場景（如影片中的下水道磚牆與水面）採用偏冷暗的墨綠與灰褐色調，飽和度與明度皆低於角色與特效至少 $40\%$，避免干擾視線。
* **特效強制置頂渲染（Render Queue / Depth Bias）：** 所有 2D 揮擊刀光、撞擊星芒與煙塵皆為面向攝影機的 `Billboard Quad`。在渲染管線中關閉 `Depth Write`，並將 `Depth Test` 設為 `Always`（或向攝影機方向偏移 $Z = -1.5\text{m}$），確保手繪特效絕對不會插入 3D 角色身體或地板模型內部造成破圖 `[00:00:09]`。

## 2. 核心 2D 手繪打擊特效逐幀拆解（Frame-by-Frame Breakdown）

LLB 的所有特效完全摒棄傳統遊戲常見的「半透明柔邊發光粒子（Soft Glow Particles）」，全面採用 **100% 不透明度（Alpha Clip / Hard Edge）的純手繪幾何色塊**。以下為以 $60\text{ FPS}$ 為基準的逐幀規格：

### 2.1 揮擊刀光／武器殘影（Swing Smears）
當 Jet 用腳踢擊 `[00:00:07]` 或 Candyman 揮動拐杖 `[00:00:06]` 時，並非靠武器模型移動，而是直接生成覆蓋整個攻擊判定框（Hitbox）的巨型 2D 塗抹色塊：
* **第 $1$ 幀（極限張開）：** 瞬間出現完整的新月形／扇形大色塊，直接涵蓋揮擊起點到終點。結構為「雙層套色」——外層為角色代表色或亮青／亮黃色（如 Candyman 的亮黃刀光 `[00:01:15]`、Jet 的青藍踢擊弧光 `[00:00:07]`），內層核心為純白色（`#FFFFFF`）。
* **第 $2 \sim 3$ 幀（尾端撕裂）：** 刀光前端固定不動，尾端開始出現不規則的鋸齒狀缺口與 $2 \sim 3$ 條分離的細長弧形速度線。
* **第 $4 \sim 5$ 幀（幾何消散）：** 刀光主體分裂成 $3 \sim 4$ 個細小的菱形或長條色塊，下一幀直接移除（不進行 Alpha 淡出）。

### 2.2 擊球瞬間的同心圓與十字星芒（Hit Sparks & Shockwaves）
當攻擊判定成功接觸球體時，在球體中心點觸發三層複合 2D 特效 `[00:00:09]`、`[00:00:23]`：
1. **蓄力鎖定核心（Hitstop Core - 頓幀期間持續存在）：**
   * **中心核：** 一個完全遮蓋球體的純白實心圓，外圍包覆一圈高飽和度的隊伍色（P1 鮮紅 `#FF1E27` / P2 亮藍 `#0088FF`）。
   * **高頻锯齒星芒：** 核心外圍帶有 $6 \sim 12$ 根不對稱的銳利尖刺（Spikes）。在頓幀期間，這組尖刺每 $2$ 幀隨機旋轉 $35^\circ \sim 70^\circ$ 並縮放 $\pm 15\%$，製造能量極度不穩定的劇烈顫動感 `[00:00:42]`。
   * **向心吸收線（Inward Speed Lines）：** 當球速超過 $50$ 時，頓幀期間球體周圍會不斷生成由外向內收縮的白色短線，模擬能量向球心壓縮。
2. **出球瞬間爆裂（Release Burst - 頓幀結束第 $1 \sim 6$ 幀）：**
   * **第 $1$ 幀：** 原本的蓄力星芒瞬間放大 $2.5$ 倍，中心轉為空心圓環。
   * **第 $2 \sim 4$ 幀：** 沿著球體射出方向的**反方向**（或垂直面），爆出一個橢圓形的「雙層氣浪環（Sonic Boom Ring）」，確認出球軌跡 `[00:00:23]`。
   * **第 $5 \sim 6$ 幀：** 圓環斷裂為數段弧線並直接消失。

### 2.3 極限球速的「作畫黑白閃」（Impact Frames）
當球速達到高速區間或使用大招擊球時（如 `[00:01:58]`、`[00:03:49]`），在頓幀開始的前 $2 \sim 3$ 幀插入全屏級別的視覺衝擊：
* **第 $1$ 幀（反白閃）：** 以球體為中心，畫面上覆蓋一個直徑佔據螢幕寬度 $40\% \sim 60\%$ 的巨型純白不規則十字星芒，將周圍場景與角色直接遮蔽。
* **第 $2$ 幀（黑洞反轉）：** 中心球體瞬間變為純黑實心圓（`#000000`），外圍十字星芒反轉為「黑底白邊」或放射狀黑白相間的閃電紋路（Zebra Impact Lines）。
* **第 $3$ 幀：** 恢復為正常的頓幀蓄力特效，透過這 $3$ 幀的強烈明暗閃爍刺激玩家視網膜。

### 2.4 球體拖尾系統（Dynamic Ribbon Trail & Sonic Rings）
球體在不同速度與技能狀態下，拖尾呈現截然不同的幾何型態：
* **基礎色帶拖尾（Ribbon Trail）：**
  * 結構為雙層套色：內核是寬度較窄的純白色帶，外層是寬度較寬的隊伍代表色（紅／藍），最外緣在高速時會多出一層黑色描邊。
  * 尾端收束：拖尾末端並非平滑變細，而是透過 Dissolve Texture 裁切成**鋸齒狀或火焰狀的分叉幾何塊** `[00:01:39]`。
* **垂直切線與音爆環（Perpendicular Slash & Rings）：**
  * 在高速飛行途中，球體軌跡上每隔固定距離會留下一道垂直於飛行方向的白色細長十字閃光與小型擴散圓環，強化「劃破空氣」的速度感 `[00:00:56]`。

### 2.5 牆面反彈、地面煙塵與擊殺碎裂（Environmental & KO VFX）
* **牆面撞擊（Wall Bounce）：** 球撞擊牆面、天花板或地板時（不消耗頓幀或僅 $1 \sim 2$ 幀極短停頓），在接觸點沿表面法線生成一個半圓形的亮黃／純白尖刺爆裂圖案，伴隨 $4 \sim 6$ 顆具備拋物線重力的方形白色碎塊向外噴濺 `[00:00:21]`。
* **角色移動與受擊煙塵（Cartoon Puff Dust）：**
  * 起跳與落地：腳底生成水平貼地的扁平白色圓環煙霧，煙霧由數個相連的圓弧塊組成，向外擴散時圓弧逐漸變細並斷開 `[00:00:33]`。
  * 頓幀滑行（Hitlag Skid）：當角色在地面擊打高速球時，會因後座力向後微幅滑行，腳底持續噴出向後的斜角塊狀煙塵。
* **擊殺爆散（KO / Get Decked Explosion）：**
  * 當角色被球擊中且生命值歸零（或一擊必殺模式）時，角色被擊飛撞向邊界牆壁產生巨型紅／白十字爆炸，同時角色周邊噴發出大量 **3D Unlit 純白與純黑的正方體碎塊（Cube Debris）** 以及放射狀塗鴉線條 `[00:00:58]`、`[00:01:59]`。

### 全屏猩紅領域（Eclipse / Red Shift Mode）Shader 實作原理
當球速 $\ge 150$ 時 `[00:02:11]`，為了讓玩家在毫秒間看清球路，系統會強制接管場景渲染：
1. **背景單色化（Background Lut / Stencil）：** 透過全域 Shader 參數 `_EclipseFactor`（在 $0.15$ 秒內由 $0$ 漸變至 $1$），將背景所有 3D 物件的色相強制映射為深猩紅色（`#8A0010`）與純黑色（`#050000`），計算公式為：
   $$\text{FinalBgColor} = \text{mix}(\text{OriginalColor}, \text{step}(0.25, \text{Luminance}) \times \text{Color}_{\text{Crimson}}, \text{\_EclipseFactor})$$
2. **水面與前景反光：** 地面水窪直接反射高對比的紅黑剪影，角色本身則維持原有高飽和度色彩並加上一圈白色外發光邊緣，讓角色與球體從紅黑背景中完全跳脫出來 `[00:04:47]`。

## 4. 猜拳博弈機制（Smash / Bunt / Grab / Parry）與角色專屬特效

影片中展示了大量高階博弈操作，每種操作都有極為明確的視覺與特效語言，讓對手能在頓幀期間瞬間識別並做出反應：

### 4.1 基礎博弈動作特效
* **普通揮擊（Swing）vs 下扣殺球（Smash）：**
  * **Smash（空中或地面重擊）：** 揮擊前角色身上會閃過一道**亮黃色十字星芒預兆**，擊中時頓幀時間比同速普通揮擊更長，且擊球火花外圍會多出一圈厚重的鋸齒狀衝擊波 `[00:00:13]`。當球速每次透過 Smash 翻倍時，速度計數字會劇烈彈跳放大。
* **短打卸力（Bunt）：**
  * 角色擺出防禦短打姿勢，接觸球體瞬間**幾乎沒有長頓幀**，發出清脆的短促敲擊聲，並生成一圈柔和的**水藍色／白色圓形擴散波紋** `[00:00:18]`。
  * 球體瞬間失去所有水平動能，轉為帶有白色虛線軌跡的緩慢垂直拋物線向上彈起，供角色接續連段。
* **招架／彈反（Parry / Deflect）：**
  * 當一方試圖蓄力或發動攻擊時，另一方精準按下短打／防禦會觸發藍白色六角形／圓形能量護盾爆裂，伴隨玻璃碎裂般的清脆重音與長達 $30$ 幀以上的獨立硬直特效 `[00:01:28]`。
* **投技（Grab & Throw）：**
  * 當對手處於 Bunt 待命姿勢時，攻擊方靠近可將球連人直接抓起（出現紫紅色鎖定圓環特效），並強制將球朝指定角度高速砸出 `[00:02:39]`。

### 4.2 影片中登場角色的特殊技（Specials）視覺演出
當畫面底部能量格（4 格）集滿時，擊球頓幀期間按下特殊鍵會觸發華麗的角色專屬視覺特效：
1. **Jet（P1 紅方）—— Bubble Pop（泡泡包裹）：**
   * **視覺表現：** 擊球瞬間畫面中央閃現 Jet 的動漫風特寫或圖騰，球體被一顆**半透明粉紅／水藍色巨型泡泡**包覆 `[00:00:26]`、`[00:01:42]`。
   * **物理與特效變化：** 球體飛行軌跡變為詭異的無重力漂浮直線，拖尾變成一串彩色大小圓泡。當 Jet 再次觸發或泡泡撞擊破裂時，會爆開一圈彩紙與水花特效，球體瞬間恢復原本的極限高速射出！
2. **Candyman（P2 藍方）—— Liquify（糖漿穿牆球）：**
   * **視覺表現：** 頓幀期間 Candyman 壞笑並注入黃色能量，球體瞬間融化變形為一團**鮮黃色（或亮青色）的液態史萊姆糖漿**，拖尾變成濃稠的水滴飛濺狀 `[00:00:48]`、`[00:02:02]`。
   * **物理與特效變化：** 當糖漿球撞擊左右牆壁時，不會反彈，而是生成一團貼牆的黃色液體漩渦，直接**穿越場景邊界（Wrap-around）**從對側牆壁瞬間鑽出，打亂對手預判！

## 5. 地面投影 UI、音響 HUD 與鏡頭／音效工程

LLB 將大量的戰鬥資訊直接融入場景與特效中，讓玩家的眼睛永遠不需要離開球體與角色。

### 5.1 地面落點投影（Floor Drop Indicator）
* 觀察影片地面 `[00:00:05]`、`[00:00:31]`，地板上始終有一個**隨球體水平 $X$ 座標即時移動的平面圓環投影（Target Decal）**。
* 圓環顏色直接對應當前球體的所屬隊伍色（紅球為紅圈、藍球為藍圈、無主球為白圈），且當球體高度越接近地面，圓環中心會向內收縮，幫助玩家在高速 2.5D 視角中精準判斷起跳與揮擊的 $X$ 軸距離。

### 5.2 底部音響 HUD（Boombox Speed Meter & Hitstop Bar）
畫面正下方的街頭音響（Boombox）不僅是裝飾，更是整場戰鬥的「節拍器」`[00:00:13]`：
* **頓幀蓄力讀條（Hitstop Progress Bar）：** 在音響上方有一條橫向進度條。每當進入擊球頓幀（Hitstop）時，進度條會以當前打擊者的顏色（紅或藍）**從左至右（或由外向內）高速填滿**。當進度條填滿至 $100\%$ 的那一幀，就是球體正式射出的瞬間！這讓雙方玩家在長達 $1$ 秒的靜止頓幀中，能精準掐算 Parry 或閃避的 Frame Timing。
* **數位球速計與音響震動：** 中央數位數字隨球速放大並變色（白 $\rightarrow$ 黃 $\rightarrow$ 紅 $\rightarrow$ 紫黑），兩側的喇叭單體（Speaker Cones）會隨著每次擊球與背景音樂的重低音（Bass）進行高頻縮放跳動。

### 5.3 數學級鏡頭運動與多層次音效（Camera & Audio Juice）
* **動態頓幀與蓄力抖動公式（Hitstop & Jitter Formula）：**
  * 設當前球速為 $v$，則頓幀幀數 $F_{\text{hitstop}}$ 可由對數或分段線性公式計算：
    $$F_{\text{hitstop}}(v) = \text{clamp}\left(\lfloor 6 + 18 \cdot \ln(0.1v + 1) \rfloor, 6, 75\right)$$
  * 在頓幀期間的每一幀 $t \in [0, F_{\text{hitstop}}]$，角色與球體的顯示座標 $\mathbf{P}_{\text{render}}$ 會在物理座標 $\mathbf{P}_{\text{logic}}$ 基礎上加上高頻震動偏移：
    $$\mathbf{P}_{\text{render}} = \mathbf{P}_{\text{logic}} + \text{RandomUnitCircle}() \times \min(0.02 + 0.0005v, 0.18)$$
* **出球瞬間的方向性鏡頭反衝（Directional Camera Punch）：**
  * 頓幀期間鏡頭保持絕對穩定（或極微幅向球體 Zoom-in $3\%$），直到頓幀結束、球體射出的第 $1$ 幀，攝影機沿著出球單位向量 $\hat{\mathbf{d}}$ 的反方向瞬間偏移，隨後以阻尼簡諧運動（Damped Harmonic Oscillator）回彈：
    $$\mathbf{Offset}_{\text{cam}}(t) = -\hat{\mathbf{d}} \cdot A(v) \cdot e^{-\zeta \omega t} \cos(\omega_d t)$$
    其中振幅 $A(v)$ 與球速成正比，創造出「球被巨力轟出去時連攝影機都被震退」的重量感 `[00:00:56]`。
* **三段式擊球音效與音高遞增（Pitch & Distortion Scaling）：**
  1. **Contact（頓幀第 $1$ 幀）：** 清脆的球棒／拳腳打擊聲 + 金屬敲擊聲。
  2. **Charge（頓幀持續期間）：** 隨頓幀長度拉伸的合成器電流蓄力音（Rising Synth Riser），其音高（Pitch）隨連擊次數與球速由 $1.0$ 逐步攀升至 $2.2$：
     $$\text{Pitch}(v) = 1.0 + \text{clamp}\left(\frac{v}{250}, 0.0, 1.2\right)$$
  3. **Release（出球第 $1$ 幀）：** 重低音 Sub-bass 爆炸聲 + 空氣撕裂音爆。當球速 $\ge 150$ 進入 Eclipse 模式時，疊加防空警報般的蜂鳴聲與全場觀眾歡呼聲 `[00:02:11]`。

## 6. 遊戲引擎實作開發路線圖（Godot / Unity 實戰檢核表）

### 第一階段：核心戰鬥物理與動態頓幀架構（第 1 週）
* [ ] **建立獨立於 `Time.timeScale` 的 `HitstopManager`：** 採用「局部計時器凍結」架構——頓幀期間僅暫停球體位移與角色狀態機推進，但保持特效播放器、鏡頭控制器、輸入緩衝（Input Buffer）與材質 Jitter 以 $60\text{ FPS}$ 正常運作。
* [ ] **實作球體物理與連擊增速曲線：** 完成普通擊球（$+2 \sim +5$ 速）、Smash（球速 $\times 1.5 \sim 2.0$ 倍）、Bunt（清零動能轉拋物線）與牆面無損反彈邏輯。
* [ ] **實作頓幀期間的 Angling（出球角度微調）：** 允許攻擊方在頓幀結束前輸入上下方向鍵改變最終射出向量 $\hat{\mathbf{d}}$，並在球體前方顯示僅自己可見（或極細微）的出球方向預告。

### 第二階段：日式手繪 2D 序列幀特效（Flipbook VFX）管線（第 2 週）
* [ ] **建立無柔邊特效 Shader：** 編寫支援 `Alpha Clip (Threshold = 0.5)` 與雙色調映射（將手繪灰階圖的黑、灰、白三階分別映射為外框黑、隊伍代表色、核心純白）的 Billboard 特效 Shader。
* [ ] **繪製並接入 5 套核心手繪 Flipbook 貼圖（每套 $4 \sim 6$ 幀）：**
  * [ ] `VFX_Swing_Smear`：大型新月揮擊刀光（含尾端幾何碎裂幀）。
  * [ ] `VFX_Hit_Spark_Loop`：頓幀期間原地旋轉縮放的鋸齒星芒核心。
  * [ ] `VFX_Release_Shockwave`：出球瞬間的反向橢圓音爆環。
  * [ ] `VFX_Impact_Frame_BW`：高速擊球前 $2$ 幀的巨型黑白十字閃光。
  * [ ] `VFX_Env_Dust_And_Bounce`：牆面尖刺噴濺與腳底環狀煙塵。
* [ ] **建構動態球體拖尾（Ribbon Trail）：** 使用 `Line2D` 或自訂 `TrailMesh`，結合噪波溶解貼圖（Dissolve Texture）製作鋸齒狀火焰尾端，並根據當前最後擊球者動態切換紅／藍配色。

### 第三階段：角色賽璐珞 Shader 與全屏 Eclipse 領域（第 3 週）
* [ ] **角色 Toon Shader 與動畫抽幀：** 實作 2-Tone 硬邊光影、背面外擴黑線，以及受擊瞬間切換純白／黑白閃爍的 `_FlashOverride` 屬性；將角色揮擊動畫曲線全數改為 Stepped 模式或每 $2 \sim 3$ 幀採樣一次。
* [ ] **全屏猩紅日蝕（Eclipse Mode）控制器：** 當偵測球速 $\ge 150$ 時，觸發全域 Shader 參數將背景轉為紅黑二值化剪影，同時將球體本體替換為「黑核紅邊」材質。
* [ ] **角色專屬 Special 狀態機：** 實作「泡泡停滯球（改變飛行阻力與泡泡包裹特效）」與「穿牆糖漿球（修改牆面碰撞為對側座標傳送與液態變形貼圖）」。

### 第四階段：場景投影 UI、音響 HUD 與音畫同步調校（第 4 週）
* [ ] **地面落點投影（Floor Decal）：** 從球體向下發射 Raycast，在地板繪製隨高度縮放並隨隊伍變色的圓環投影。
* [ ] **音響 HUD（Boombox UI）綁定：** 實作中央數位球速錶、隨重低音縮放的喇叭單體，以及與 `HitstopManager` 剩餘幀數完全同步的**頓幀蓄力讀條**。
* [ ] **方向性鏡頭震動與三段式音效合成：** 接入阻尼彈簧鏡頭反衝系統（Camera Punch），並將 Contact / Charge Riser / Release Boom 三段音效綁定球速 Pitch 曲線。
