詳細研究

這部對戰實機影片（http://www.youtube.com/watch?v=4GLOxEmgoEI ）比前一部高段位比賽影片包含了更多完整的 UI 流程（選角、買角色、選關、過場、結算）、貼身零距離連續互拍（Point-Blank Clashing）、3D 自由視角擊殺特寫（3D Kill Cam），以及球速破千（1000+ 至 3500+）時的「第三階段全屏色彩反轉領域」。

以下針對這部影片中展示的關鍵技術與美術細節，為你的 Godot + Blender「完美格擋動能格鬥遊戲」 進行逐幀級別的深度拆解與研究：

1. 貼身零距離「連續互拍 / 完美格擋交鋒」視覺拆解（[08:55] - [09:11] & [10:18] - [10:27]）
影片中 Dice 與 Dust & Ashes 在工廠關卡上演了一段長達 15 秒的「面對面零距離瘋狂對抽」，這正是你前面提到「雙方輪流完美格擋、動能無限疊加」的最佳視覺範本：

紅藍交替的同心圓護盾（Alternating Clash Rings）：

當雙方貼身輪流觸發格擋／反擊時 [08:56]，中心點會以極高頻率交替炸開「紅白雙色」與「藍白雙色」的 2D 手繪同心圓與十字星芒 [08:58]、[09:00]。

實作重點： 每次格擋換手時，新的 2D 撞擊特效必須直接覆蓋並強制銷毀上一個特效，且圓環外圍伴隨 6 至 8 根細長白色放射線（Speed Spikes），讓玩家一眼看出現在主動權在誰手上。

誇張的垂直刀光切割畫面（Vertical Smear Slices）：

在 [09:02] 到 [09:08] 的連續停滯期間，每次揮擊都會刷出一道幾乎頂天立地（佔據畫面高度 70%）的純白手繪弧形刀光。

注意這些刀光完全沒有柔邊（No Soft Glow），而是像漫畫沾水筆畫出的銳利白色色塊，停留 2 幀後分裂成兩三條細線消失。

球體（或動能核心）的果凍擠壓變形（Squash & Stretch）：

仔細看 [08:59] 與 [10:23] 的停滯瞬間，中間的球體並不是圓形的，而是被壓扁成一個垂直的橢圓餅狀（寬度縮至 50%，高度拉長至 150%），並在原地左右劇烈顫抖。放到你的格鬥遊戲裡，當雙方拳頭或武器交鋒卡住（Clash）時，可以在接觸點生成一顆被壓扁的高亮能量球核心來呈現這種「力量被死死夾住」的物理張力。

2. 3D 動漫風「擊殺特寫鏡頭（Kill Cam / Finish Cut-in）」深度拆解（[01:19]、[03:36]、[05:59]）
這部影片清楚展示了《Lethal League Blaze》最爽快的終結演出——當高動能攻擊命中對手時，2.5D 橫向視角會瞬間切換為 3D 廣角特寫鏡頭：

一幀切換純紅放射背景（Red Sunburst Backdrop）：

命中瞬間 [01:19]，原本的 3D 場景完全隱藏，背景瞬間替換為高飽和橘紅色底 ＋ 暗紅色同心圓標靶與放射線的 2D 背景層。

地面只保留角色腳下一塊純黑色的硬邊落影（Hard Drop Shadow）[02:53]，讓角色與背景產生極致的剪紙漫畫感。

3D 戲劇化運鏡與兩段式推拉（Two-Stage Dramatic Camera）：

第一拍（命中定格）： 攝影機瞬間切到受擊者臉部或身體被擊中部位的超廣角近距離特寫（FOV 約 70~80，微仰角）[02:45]、[05:31]。此時受擊部位緊貼著被壓扁的球體與巨型亮黃色尖刺爆炸火花，角色模型做出極度扭曲的受擊顏藝 Pose。

第二拍（遠景對比鏡頭）： 停留約 0.4 秒後，鏡頭硬切（Hard Cut）或極速拉遠至攻擊者背影／側面為前景、受擊者在遠處中心點爆炸的構圖（例如 [02:24]、[05:48]、[07:55]）。這種「前景巨大攻擊者 ＋ 遠景渺小受擊者」的透視對比，把「一拳把人轟飛到天邊」的爽感拉到最滿。

擊飛後的「純白石膏化」與黑煙翻滾（[01:22]、[06:03]）：

特寫結束切回原場景時，被擊敗的角色全身材質會變成純白底色配粗黑網格線（類似石膏像或漫畫網點白化）[01:22]，高速撞牆反彈，並拖出一條由一團團黑色塗鴉圓球組成的濃煙軌跡 [02:35]。

3. 三階段「背景領域變色（Stage Color Shift）」完整進階規律（[00:24] - [00:28] & [07:45] - [07:53]）
前一部影片只看到紅黑領域，但這部影片在速度飆破 1000 到 3584 時，展示了完整的三階段全屏領域進階，非常適合套用在你的「完美格擋疊加層數（Surge Level）」上：

第一階段（中高速，速度約 150+）：場景專屬霓虹配色／猩紅領域

不同關卡有不同的高對比配色：精神病院與廢墟關卡會切換為猩紅配純黑[01:16]、[07:07]；而地下鐵與隧道關卡則會切換為純黑底色配螢光綠線條（Cyber Neon Green）[00:24]、[03:08]。

第二階段（極高速，速度破 700~1000+）：白紫反轉／青白負片領域（Inverted Hyper Mode）

在 [00:26]（速度 757 -> 1092）與 [07:49]（速度 1014 -> 2703），整個畫面會伴隨一道閃光，瞬間反轉為刺眼的亮白色／亮青色天空配深紫色／純白地面！

此時球體與攻擊軌跡反而變成純黑色刀光（Black Slash Arc）[00:26]、[07:49]——因為背景全亮白了，用純黑刀光才能維持最高對比度！

第三階段（神仙打架，速度 3500+）：紅黑與青白高頻閃爍切換

在 [07:52] 速度飆到 3584 時，每次擊球都會在「亮青白負片」與「暗紅黑洞」之間來回切換，搭配震耳欲聾的音爆聲，視覺壓迫感達到頂峰。

5. 如何將這部影片的精華直接加進你的 Godot 專案？（實作補充包）
針對這部影片展示的「3D 特寫擊殺鏡頭（Kill Cam）」與「破千速負片反轉領域（Hyper Inverted Mode）」，你可以直接在先前的 Godot 架構中加入這兩個極具代表性的機能：

A. 在 Godot 4 實作「瞬間紅底 3D 擊殺特寫（Kill Cam）」
不需切換場景，只需在主場景配置一台專屬的 KillCam3D，並在她的正後方掛一個跟隨鏡頭的純紅放射背景平面（MeshInstance3D）：

GDScript
# 在 ClashManager 或 CameraController 中呼叫此函數觸發終結特寫
func trigger_kill_cam(attacker: Node3D, victim: Node3D, hit_pos: Vector3) -> void:
	# 1. 變更 Camera3D 的 Cull Mask：只渲染第 2 層 (角色與打擊特效)，隱藏第 1 層 (3D場景建築)
	main_camera.cull_mask = 0b00000010 
	
	# 2. 開啟鏡頭正後方的紅底放射線背景板與純黑地面落影
	red_sunburst_backdrop.visible = true
	
	# 3. 第一拍：超廣角貼臉特寫 (0.45 秒)
	main_camera.fov = 75.0
	var cam_offset = (victim.global_position - attacker.global_position).normalized() * 1.8
	main_camera.global_position = hit_pos + Vector3(cam_offset.x, 0.4, 2.2)
	main_camera.look_at(hit_pos, Vector3.UP)
	
	await get_tree().create_timer(0.45).timeout
	
	# 4. 第二拍：硬切到攻擊者背影遠景 (0.35 秒)，重現 [00:05:48] / [00:07:55] 的經典構圖
	main_camera.fov = 50.0
	var behind_attacker = attacker.global_position - (victim.global_position - attacker.global_position).normalized() * 2.5
	main_camera.global_position = behind_attacker + Vector3(0, 1.2, 1.5)
	main_camera.look_at(victim.global_position, Vector3.UP)
	
	await get_tree().create_timer(0.35).timeout
	
	# 5. 切回正常 2.5D 橫向視角，並將受擊者切換為純白石膏材質擊飛
	red_sunburst_backdrop.visible = false
	main_camera.cull_mask = 0b00000011
	reset_to_2d_fighting_view()
	victim.apply_plaster_white_knockout()
B. 擴充全域領域 Shader：加入「1000+ 極速亮白負片領域」（對應 [07:49]）
將我們上一輪寫的 eclipse_active 全域變數改為整數 global uniform int surge_stage（0 = 正常、1 = 紅黑/螢光綠領域、2 = 亮青白負片領域 + 純黑刀光）：

當 surge_stage == 2 時，背景 Shader 直接將明度反轉並染上高飽和青白色（vec3(0.4, 1.0, 0.95)），而角色的刀光與打擊火花 Shader 則強制輸出純黑色（vec3(0.0, 0.0, 0.0)）。這樣當雙方完美格擋疊加到第 8 層以上時，全場突然「白晝化」並劈出漆黑閃電，視覺震撼力會比單純的紅黑背景再往上翻倍！
