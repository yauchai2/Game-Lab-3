Godot + Blender

用 Godot 4 + Blender 來實作這套「完美格擋動能疊加（Kinetic Clash）」系統非常合拍。透過 glTF/GLB 管線，你可以將 Blender 製作的低模／賽璐珞角色與誇張變形骨架（Smear Frames）無縫導入 Godot，並利用 Godot 的 ShaderMaterial 與 Tween 實現 60 FPS 幀級別精準的頓幀與視覺爆發。

以下為你整理 Blender 到 Godot 4 的完整實作架構、核心 GDScript 程式碼與 Shader 實作指南，你可以直接複製到專案中使用或交給 AI 擴充：

一、Blender 資產與動畫準備管線（glTF 導出規範）
為了做出《Lethal League Blaze》那種極具張力的街頭卡通感與誇張動態，Blender 端需按以下規格設置：

1. 角色模型與雙重描邊準備
法線平滑處理： 為了讓三階色塊（Cel Shading）乾淨不破碎，建議將臉部與軀幹的法線向中心球體傳遞（Data Transfer Modifier），避免陰影出現髒點。

色彩屬性（Vertex Color）： 用頂點色標記固定陰影區域（如脖子下方、衣服皺褶內側），導出 .glb 時勾選 Vertex Colors，供 Godot Shader 讀取。

2. 「零插值（Constant Interpolation）」與塗抹幀（Smear Frames）
階梯式動畫（Stepped Animation）： 在 Blender 的 Nonlinear Animation / Graph Editor 中，將關鍵姿勢（Key Poses）設為 Constant（常數插值）或高斜率曲線，模擬日式手繪動畫 12 FPS / 24 FPS 的卡頓力度，不要用平滑的 60 FPS 補間。

蓄力與爆發姿勢分離：

Attack_Charge（完美格擋後的頓幀蓄力姿勢）：身體極度後仰或壓低重心，持續循環抖動。

Attack_Release（頓幀結束第 1 幀）：利用 Shape Keys（形態鍵） 或專屬拉伸骨骼（Stretch Bones），將揮拳的手臂或武器在第 1 幀拉長至原本的 2 倍大（Smear Frame），第 3 幀迅速收縮回正常比例。

3. 2D 刀光與撞擊網格（Mesh Flipbook）
除了在 Godot 用 AnimatedSprite3D 播序列幀外，針對「揮擊大刀光（Swing Arc）」，直接在 Blender 建一個彎曲的新月形平面（Crescent Plane），綁在角色攻擊判定的骨骼前端，並展開標準 UV（0 到 1），方便在 Godot 中用 Shader 刷過雙色塊。

二、Godot 4 核心戰鬥架構（Scene Tree 與 Autoload）
建議在 Godot 4 中建立一個全域單例（Autoload）ClashManager.gd，專門統籌動能疊加、局部頓幀（不卡死特效與鏡頭）與輸入緩衝。

1. 全域動能與頓幀控制器：ClashManager.gd (Autoload)
GDScript
extends Node

signal clash_triggered(surge_level: int, hitstop_frames: int, defender: Node3D)
signal clash_released(surge_level: int, release_type: String, attacker: Node3D)
signal eclipse_mode_changed(is_active: bool)

# 核心動能參數
var surge_level: int = 1
var max_surge_level: int = 10
var eclipse_threshold: int = 5 # 達到 Lv.5 觸發全屏紅黑領域

# 頓幀計時（以 60 FPS 物理幀為基準）
var hitstop_frames_remaining: int = 0
var is_in_hitstop: bool = false

# 完美格擋判定窗口（隨等級遞減，防止無限打鐵）
func get_parry_window_frames() -> int:
	return maxi(3, 8 - (surge_level / 2))

# 計算動態頓幀長度：越快越慢
func calculate_hitstop_frames(level: int) -> int:
	return mini(70, 8 + (level * 6)) # 從 14 幀一路拉長到最高 70 幀 (約1.16秒)

func _physics_process(_delta: float) -> void:
	if is_in_hitstop:
		hitstop_frames_remaining -= 1
		if hitstop_frames_remaining <= 0:
			_end_hitstop()

# 當防守方成功觸發「完美格擋」時呼叫
func trigger_perfect_parry(attacker: Node3D, defender: Node3D, hit_position: Vector3) -> void:
	surge_level = mini(max_surge_level, surge_level + 1)
	hitstop_frames_remaining = calculate_hitstop_frames(surge_level)
	is_in_hitstop = true
	
	# 凍結雙方角色的狀態機與物理，但不凍結全域 Engine.time_scale
	attacker.set_hitstop_freeze(true)
	defender.set_hitstop_freeze(true, true) # defender 獲得反擊輸入權
	
	# 檢查是否進入紅黑領域 (Eclipse Mode)
	if surge_level >= eclipse_threshold:
		RenderingServer.global_shader_parameter_set("eclipse_active", true)
		eclipse_mode_changed.emit(true)
		
	clash_triggered.emit(surge_level, hitstop_frames_remaining, defender)

func _end_hitstop() -> void:
	is_in_hitstop = false
	get_tree().call_group("fighters", "set_hitstop_freeze", false)

# 回合重置（有人被擊飛時呼叫）
func reset_clash() -> void:
	surge_level = 1
	is_in_hitstop = false
	RenderingServer.global_shader_parameter_set("eclipse_active", false)
	eclipse_mode_changed.emit(false)
2. 角色格擋、頓幀抖動與三選一反擊：FighterController.gd
掛載於 CharacterBody3D 上（需加入 "fighters" Group），負責處理頓幀期間的模型高頻抖動（Jitter）與蓄力拐拍／瞬發／破防投技輸入：

GDScript
extends CharacterBody3D

@export var visual_root: Node3D # 指向 Blender 匯入的模型根節點（用來做抖動而不影響碰撞體）
@export var anim_player: AnimationPlayer

var is_frozen: bool = false
var can_buffer_counter: bool = false
var buffered_action: String = "INSTANT" # INSTANT, DELAYED_CHARGE, GRAB
var extra_charge_frames: int = 0

var base_visual_pos: Vector3

func _ready() -> void:
	add_to_group("fighters")
	base_visual_pos = visual_root.position

func _physics_process(delta: float) -> void:
	if is_frozen:
		_process_hitstop_jitter()
		if can_buffer_counter:
			_read_hitstop_inputs()
		return
		
	# 如果格擋方選擇了「延遲蓄力拐拍 (DELAYED_CHARGE)」，在頓幀結束後繼續短暫蓄力
	if extra_charge_frames > 0:
		extra_charge_frames -= 1
		_process_hitstop_jitter(1.5) # 蓄力期間抖動更劇烈
		if extra_charge_frames == 0:
			_execute_counter_attack("DELAYED_CHARGE")
		return

	# 正常移動與物理邏輯
	move_and_slide()

# 頓幀期間的模型高頻隨機震動 (LLB 招牌蓄力感)
func _process_hitstop_jitter(multiplier: float = 1.0) -> void:
	var intensity: float = 0.02 * ClashManager.surge_level * multiplier
	visual_root.position = base_visual_pos + Vector3(
		randf_range(-intensity, intensity),
		randf_range(-intensity, intensity),
		0.0
	)

# 頓幀期間讀取玩家的心理戰變招指令
func _read_hitstop_inputs() -> void:
	if Input.is_action_pressed("attack_heavy"):
		buffered_action = "DELAYED_CHARGE" # 按住重擊：延遲蓄力拐拍
	elif Input.is_action_just_pressed("grab"):
		buffered_action = "GRAB" # 投技：直接破防對手的格擋
	elif Input.is_action_just_pressed("attack_light"):
		buffered_action = "INSTANT" # 瞬發反擊

func set_hitstop_freeze(freeze: bool, is_parry_winner: bool = false) -> void:
	is_frozen = freeze
	if freeze:
		anim_player.pause()
		can_buffer_counter = is_parry_winner
		buffered_action = "INSTANT" # 預設瞬發
	else:
		visual_root.position = base_visual_pos
		anim_player.play()
		if can_buffer_counter:
			can_buffer_counter = false
			if buffered_action == "DELAYED_CHARGE":
				# 額外壓縮 15 幀（0.25秒），騙對手提早按出格擋
				extra_charge_frames = 15
				anim_player.play("Attack_Charge_Hold")
			else:
				_execute_counter_attack(buffered_action)

func _execute_counter_attack(action_type: String) -> void:
	ClashManager.clash_released.emit(ClashManager.surge_level, action_type, self)
	match action_type:
		"INSTANT":
			anim_player.play("Counter_Instant_Smear")
		"DELAYED_CHARGE":
			anim_player.play("Counter_Overdrive_Smash")
		"GRAB":
			anim_player.play("Counter_Kinetic_Grab")
三、Godot 4 視覺與 Shader 實作（反白、雙色刀光與紅黑領域）
在 Godot 的 Project Settings -> Shader Globals 中，新增一個全域變數：

名稱：eclipse_active，類型：bool，預設值：false。

1. 角色賽璐珞 + 受擊瞬間純白剪影 + 紅黑領域切換 Shader (fighter_toon.gdshader)
OpenGL Shading Language
shader_type spatial;
render_mode unshaded; // 使用自訂光照計算以確保絕對銳利的色塊

global uniform bool eclipse_active;
uniform sampler2D albedo_tex : source_color;
uniform vec4 shadow_tint : source_color = vec4(0.4, 0.35, 0.5, 1.0);
uniform float flash_white : hint_range(0.0, 1.0) = 0.0; // 受擊或格擋瞬間設為 1.0
uniform vec4 team_color : source_color = vec4(0.0, 0.8, 1.0, 1.0);

void fragment() {
	vec4 tex = texture(albedo_tex, UV);
	
	// 1. 紅黑領域 (Eclipse Mode) 高反差剪影模式
	if (eclipse_active) {
		float luma = dot(tex.rgb, vec3(0.299, 0.587, 0.114));
		// 角色轉為純黑剪影配亮色邊緣/色塊
		ALBEDO = mix(vec3(0.02, 0.0, 0.02), team_color.rgb, step(0.65, luma));
	} else {
		ALBEDO = tex.rgb;
	}
	
	// 2. 完美格擋 / 受擊瞬間純白閃光 (Impact Flash)
	ALBEDO = mix(ALBEDO, vec3(1.0, 1.0, 1.0), flash_white);
}
2. 背景場景瞬間切換「猩紅黑洞領域」Shader (stage_eclipse.gdshader)
掛在所有 3D 背景建築物材質上，當 surge_level >= 5 時，1 幀內將整個街頭場景變成紅黑剪影：

OpenGL Shading Language
shader_type spatial;

global uniform bool eclipse_active;
uniform sampler2D bg_texture : source_color;
uniform vec3 eclipse_red : source_color = vec3(0.85, 0.05, 0.12);

void fragment() {
	vec4 col = texture(bg_texture, UV);
	if (eclipse_active) {
		float gray = dot(col.rgb, vec3(0.299, 0.587, 0.114));
		// 二值化閾值：暗部純黑，亮部猩紅
		ALBEDO = mix(vec3(0.03, 0.0, 0.02), eclipse_red, step(0.4, gray));
		EMISSION = ALBEDO * 0.8;
	} else {
		ALBEDO = col.rgb;
	}
}
3. 全屏「黑白閃（Impact Frame）」後處理 (impact_frame_post.gdshader)
在場景最上層放一個 CanvasLayer -> ColorRect（設為 Full Rect），當完美格擋或高倍率重擊發生時，開啟顯示 2 幀（約 0.033 秒） 後關閉，瞬間製造熱血動畫的黑白作畫閃光：

OpenGL Shading Language
shader_type canvas_item;

uniform sampler2D screen_texture : hint_screen_texture, filter_nearest;
uniform bool invert_phase = false; // 第 1 幀設 false (黑底白光)，第 2 幀設 true (白底黑線)

void fragment() {
	vec3 scr = texture(screen_texture, SCREEN_UV).rgb;
	float luma = dot(scr, vec3(0.299, 0.587, 0.114));
	float bw = step(0.45, luma); // 強制轉為極端黑白二值化
	if (invert_phase) {
		bw = 1.0 - bw;
	}
	COLOR = vec4(vec3(bw), 1.0);
}
四、方向性鏡頭震動與 FOV 推拉 (ClashCamera3D.gd)
LLB 的鏡頭不會無規律亂晃，而是「在格擋瞬間稍微拉近（Zoom In 壓迫感），在頓幀結束出招的那 1 幀沿著攻擊方向猛烈震動（Directional Punch）」：

GDScript
extends Camera3D

var shake_offset: Vector2 = Vector2.ZERO
var shake_velocity: Vector2 = Vector2.ZERO
var spring_stiffness: float = 450.0
var spring_damping: float = 22.0
var default_fov: float = 55.0
var target_fov: float = 55.0

func _ready() -> void:
	default_fov = fov
	ClashManager.clash_triggered.connect(_on_clash_triggered)
	ClashManager.clash_released.connect(_on_clash_released)

func _process(delta: float) -> void:
	# 阻尼彈簧物理計算鏡頭回彈
	var force: Vector2 = -spring_stiffness * shake_offset - spring_damping * shake_velocity
	shake_velocity += force * delta
	shake_offset += shake_velocity * delta
	
	h_offset = shake_offset.x
	v_offset = shake_offset.y
	fov = lerpf(fov, target_fov, delta * 18.0)

# 1. 完美格擋瞬間：鏡頭瞬間推進 (Zoom-in)，聚焦蓄力張力
func _on_clash_triggered(surge_level: int, _frames: int, _defender: Node3D) -> void:
	target_fov = maxf(38.0, default_fov - (surge_level * 2.0))
	apply_directional_impulse(Vector2(0, 1), 2.5) # 垂直微震一下

# 2. 頓幀結束出招瞬間：鏡頭恢復並沿攻擊方向猛烈震動
func _on_clash_released(surge_level: int, _type: String, attacker: Node3D) -> void:
	target_fov = default_fov
	var dir_x: float = signf(attacker.global_transform.basis.z.x)
	var power: float = 4.0 + (surge_level * 2.5)
	apply_directional_impulse(Vector2(dir_x, 0.3).normalized(), power)

func apply_directional_impulse(direction: Vector2, strength: float) -> void:
	shake_velocity += direction * strength
