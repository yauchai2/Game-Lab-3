# wev／worldwidewev 候選音樂調查

2026-11-09 使用者指定藝術家，允許整體換曲／音效；其後確認尚未取得授權，先完成選曲與接入規劃。

[catalog.json](catalog.json)保存公開頁面必要欄位：7 個來源 HTTP 200、15 首《OST》曲目、兩首 SoundCloud 作品的授權／下載旗標、擷取時間與回應雜湊。Bandcamp 專輯／曲目標示 All Rights Reserved，SoundCloud 兩首亦為 all-rights-reserved。

沒有下載音訊、抽取串流、購入、聯絡藝術家或改遊戲音訊。沒有完成實聽／BPM／循環點分析；downloadable=true 不等於遊戲授權。原始頁面的追蹤識別碼及媒體網址不入庫。

完整候選用途、待授權項、資料結構、混音與驗收見 [WEV_MUSIC_PLAN.md](../../../docs/WEV_MUSIC_PLAN.md)。目前錄用狀態為 `blocked_missing_license`，現有 CC0 音訊保留。
